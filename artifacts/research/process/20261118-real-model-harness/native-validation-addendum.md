# 相机绑定闭合后的完整回放

**修复后的移动相机通过了一次预登记完整协议回放。** 前份独立报告已确认原两项故障在 CPU 上均被拒绝。本次回放在同一冻结源码上完成 8 个原始技能、9 段动作和 7,702 个模拟步，worker 为 SUCCEEDED，组件为 COMPONENTS_COMPLETED。独立物理评分成功，稳定放置 9.4417 s，无记录到的安全违规。两张终端标记帧均为 OBSERVED。JUnit 记录 1 项通过，用时 33.72 s。

复核范围为小型机器报告、冻结源码清单、预登记、启动收据、JUnit 和归档探查摘要。步骤报告记载运行前后 23 项计划输入及 50 项生产源码和 4 项测试字节匹配，沿用相机绑定修后的冻结版本。复核核对了冻结清单、JUnit、探查摘要、预登记与启动收据的 SHA256。逐帧数据引用本轮步骤报告的检查结果，本补记未重新渲染、读取批量 raw 或调用模型。

- 归档探查一次写入同文件系统的 8 帧、32 个文件，共 4,928,135 字节，最慢单帧为 2.936 ms。完整回放的 778 张伺服帧均有匹配的生产标定摘要。10 个恢复组均通过相机完整位姿、同步模拟时刻、观测身份和命令序列核验；777 次记录的安全检查全部允许。最大采样加 IK 为 91.403 ms，已计入被动跟踪开销，低于原 100 ms 门限。
- 此次结果满足原剩余 44102、44103、44104 三个真实 seed 的开发运行前置条件。此次使用冻结协议响应，实际模型加载、本地生成及云 API 均为零。三个真实 seed 的结果与配额由真实运行记录单列。
