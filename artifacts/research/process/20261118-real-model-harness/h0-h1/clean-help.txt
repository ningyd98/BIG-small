usage: bigsmall-harness [-h] [--version]
                        {validate,doctor,prepare,run-simulation,evidence} ...

Validate, prepare and explicitly run the registered BIGsmall simulation.

positional arguments:
  {validate,doctor,prepare,run-simulation,evidence}
    validate            validate offline configuration
    doctor              inspect resource requirements without model startup
    prepare             run the original no-render, no-model preparation
    run-simulation      explicit real-model MuJoCo component diagnostic
    evidence            verify an existing local episode manifest

options:
  -h, --help            show this help message and exit
  --version             show program's version number and exit
