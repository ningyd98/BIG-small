# Pure owner source API

`VisualOwnerIdentity(job_id, run_id, attempt, worker_id, lease_id, owner_epoch, episode_id, task_id, plan_id, robot_id)` validates opaque non-placeholder identity values. These values are bindings, not authenticated live leases.

`OriginalActionRequirements(original_step, preconditions, postconditions, allowed_error_m, sensor_requirements, ordinary_ttl_s, expected_duration_s, policy_source_hashes)` stores a detached original compiled TaskStep and immutable canonical ConditionSpec requirements. `to_payload()` and `digest()` serialize original step/hash, canonical names/target IDs/tolerances/sensors, error/TTL/duration, timeout/retry, and policy sources. It contains no VisualEvidence, future condition truth, receipt or acceptance token. Parent conditional-intent PLANNING_ONLY code may reuse this payload unchanged.

`freeze_original_visual_plan(*, identity, contract, proposal_hash, role_bundle_hash, compiler_source_hashes, source_hashes, requirements, dependencies, task_deadline_at, verification_deadline_at, registered_at, previous=None) -> VisualOriginalPlan`. The returned contract property is detached. Requirements, dependency graph and all sources are immutable. `to_payload()`, `digest()`, `freeze_inputs()` are available. Supplying previous enforces same-version byte identity, monotonic new plan/sequence and non-extended deadlines. An initial call alone cannot establish durable history; a future owner repository must compare its existing authoritative record.

`DeterministicGroundingPolicy(policy_id, version, source_hashes, tcp_velocity, acceleration, clearance_m, minimum_height_m)` supports the explicit rgbd-top-grasp-v1 recipe only. `GroundingFrameInputs(observation_id, observation_checksum_sha256, episode_id, calibration_version, grasp_tcp, destination, support_height_m, source_hashes)` freezes input coordinates and source provenance. Both expose to_payload/digest.

`GroundingDurationCheck(grounded_step, observation_id, observation_checksum_sha256, original_plan_hash, grounding_policy_hash, expected_duration_s, checked_at, source_hashes)` binds a fresh longer-horizon calculation to the exact step/frame/plan/policy. to_payload/digest retain exact timestamp and sources. It is not a geometry/motion certificate.

`bind_step_grounding(original, *, original_step_id, grounded_step, online, source_checkpoint, current_identity, owner_revision, state_generation, grounding_inputs, grounding_policy, now, required_duration_s=None, duration_check=None) -> StepGroundingBinding` validates the current first-pending cursor, all identity/version/frame/checkpoint/source values, exact deterministic parameters and preserved original timeout/retry/duration. It retains separate immutable original_requirements and detached grounded_step with empty legacy lists. Hashes bind the complete frame input and optional duration calculation, plus the union of all calculation sources. Expiry is the minimum of original task/verification/contract deadlines and actual frame capture plus minimum registered TTL/condition max age. A larger duration requires the fresh exact duration check; a smaller horizon is rejected.

All output scope values are fixed SOURCE_BINDING_ONLY. No repository, stage, activate, resume, dispatch, actual-owner/METHOD/native admission or accepted flag exists. Later ROOT-owned registration must authenticate the live lease/source identities, preserve this original contract and add separate grounding records with durable CAS; it must keep all native canonical/Safety/Skill gates.
