# G1 B03 RELEASE 与 RETREAT 交接的必要前置

规划模型 gpt-6.2-astra。基线 4493ad26463358d19d2b789d1417253f1cdc28db。

B03 偏移 P=(−10,−30) mm 已取得真实 PLACE、原生开爪成功返回、31/31 帧联合 RELEASE 驻留、241/241 步独立物理。原位 0/31。P 真 RELEASE/PRE 有可用姿态与支撑，但原归档缺在线合格的同会话 PLACE/POST 和载物历史，旧末张 DWELL 也不构成新 RETREAT/PRE。原完整 worker 要求由原登记名义后端形成完整 PRE/FEEDBACK、先前阶段 PASS、同曝光与真实时钟，B03 影子路线未取得这份资格。当前问题是已知真实状态是否至少位于冻结控制交接和制停的测试域。

1. 只读复核 plan.json 的冻结源码、先前物理/相机封包和原交接版。逐项核两个路线的原生 reset、实拍校验、双 pass 和无渲染复演的九维曝光编码器。只取 B/P 各自的真实 RELEASE/PRE 和末张 DWELL，封存四个无组名的白名单输入。阶前档案用真实物理步的关节、速度和实际 ctrl，目标和命令速度按原后端同 tick 前缀计算。PRE 只接到真实 PLACE 最后一条 joint_target，hold/OPEN 保留在曝光之后。末张 DWELL 使用原 hold/open 命令。真实载物位姿和接触不供预测器读取。
2. 对每个输入保留原 role、episode、frame_id、checksum、曝光时刻，原标记及 rigid_pose 独立复算。原位没有当前姿态时保留拒绝。末张 DWELL 的输入角色原样保留，以反事实数学候选核对 RETREAT 的必要交接；没有派发或假冒实际阶段。
3. 从冻结 handoff_motion 计算原 exact grouped 椭球距离、允许开合类别、全部匹配参考及制停窗。原 RELEASE 额定 pre+0…240，RETREAT 为 0…8。若域内，用与原完全一致的 panel-primary/panel-start 投影体积检查、同一 2×BAND 误差和仅在条件许可时适用的原工件台面裁剪，记录包络间隙、限制件和体积结论。允许台面裁剪仅是条件性上界，严格结果和该假设分列。两者皆失败才确认相应必要条件失败。未建立当前完整条件时不签发原 PRE。
4. 两次独立冷读，封存前禁止打开封存物理真值和实验分组映射。核对同组坐标、闭爪和张爪参考、原关闭/开爪顺序、错误帧和校验、ctrl/goal 不可互换、错速度、缺姿态、漏延迟、椭球内外对照。两份规范结果逐字节相同。预测域为先前假设的必要边界，结果不设 LocalClearance.isolated_scene 或先前阶段 PASS，也不给出在线、撤离或整机资格。

实际只运行两次 CPU 冷读，各四槽，按原登记保留全部拒绝。新增初始化/积分、光学曝光、GL、控制、RELEASE、RETREAT、整机、正式、独立正式评分、硬件和远程全部为零。任何输入、身份或独立复算不一致即止。
