# G1 原生视觉抓放开发修复计划

模型 `gpt-6.2-astra`。研发基线 `b11e9a86387b87b27fc31b4c0fec974a7dc4f65f`。目标是在新的受控 MuJoCo 开发场景，从顶视 RGB-D 识别可见 ID，经原控制器实际抓起、搬运及放稳。软件、独立开发实跑、正式八槽分别报告。原相机、分辨率、原腕姿、可见 ID7/8、原关节/夹爪控制、技能与安全/时限、目标区身份、评分窗口保持。

## 原始证据与工作假设

上一轮两新摆放各 303 组，231 组筛除，72 组有名义夹面及静力见证、净空未证。两条中心旧经路分别在第 1221 步右指碰 ID8 板、第 1228 步左指碰 ID7 梁。原腕最近面对齐差 0.127°、2.228°；小角度误差是否允许稳定双侧接触要靠实际夹持衡量。全矩阵从采图到决定 4.088、4.137 秒；旧接口两例 35.45、36.10 ms 仅组件正控。原生技能派发 0，新摆放完整抓放 0。详见同目录 JSON 锁定的原始读回、原资格与评分源。现有完整 raw 留在本地。

H1 将支架从两指闭合面移到非夹持面可同时保全固定腕中心抓点及较大标记的实时可见性。H2 在认证的隔离静态台面，经过注册的环境、RGB-D 差分、FK 和有效跟踪/停车实测能限定每一小段的运动空间。H3 在静止时确定路线、移动时逐帧只检查已选目标，完整周期可达 100 ms。均待验证，尤其是抬升和放下时的可见性、载板重心及实际摩擦。

## A　新开发装配与光学、力学诊断

- [ ] 首先从原 70 mm 方块、原夹爪和原双标材质/编码构造一个独立开发 MJCF 及注册描述。原固定腕沿世界 Y 闭合，设计物体 X 的正负两端对称引出实体薄梁/载板，保留约 75 mm 印刷标记及静区，梁避开两指和掌的完整扫掠。按实际手盒、夹持高度、桌面及放置边界确定长度和高度，尺寸对全部摆放共用。比较原中心与非居中目标时从零偏移优先；若双板在上方遮住目标区或与本体/桌面相交，可试同一设计空间的低位端翼、一体载体或在本体物理表面印标；每一代保留失败记录。不得用独立悬浮标记。材质图案依附真实碰撞几何，所有有体积的板梁保留质量、惯量、接触材料和碰撞。记录原始质量、编译质量/质心/惯量、碰撞类别、实测初始余隙、方块侧面外露尺寸、板梁清单、TCP与标记外参。
- [ ] 真实原相机采集静止、下降/闭合近姿、抬升及目标区代表图，记录每 ID 像素宽、识别与单标/双标回投、方块顶心差、手遮挡、区域定位及原允许降级行为。部分关节姿势可在独立诊断夹具复位测量，计作诊断。真实正控用已知无障碍的本体；原梁/板与真实禁碰对必须仍被检出。区域目的标记/颜色依据原阶段协议，物体移动后不得以目标像素替代目的区。
- [ ] 独立夹持诊断在原摩擦、原夹力（若用较低夹力只算探索）、固定腕与原接触检测下，从静止张爪开始，经原闭合执行器实际接触，测同步指宽、左右接触物体、力/滑移、目标偏移及姿态、不同步触碰、抬起保持及静置。可用单独诊断初始姿态，不得瞬移实现夹持、锁物、改摩擦、加吸附。测试含 0、±1°、±2.5° 的角差和中心误差，记录连续的开度/投影/双侧搭接范围与失败；通过实测与保守余量建立此次装配的局部准入区，外推须另验。实际每次检查该帧角度的不确定度、搭接、开口与实际接触，过界拒绝；原腕命令保持原四元数。单个离散成功不视为任意角可行。对训练样本追踪接触中旋转、关节跟踪和停止产生的最大偏差。测得的范围仅适用于本装配、速度、负载和测试区。

## B　背景登记与在线单目标检查

- [ ] 开发专用登记表绑定原相机内外参、桌面/目的区、固定障碍、场景 XML/材料/载板、采集帧、FK 手模型、执行配置和初态边界。以同一原相机独立观测空台（独立校准状态中移开活动物），与已登记静态布局交叉核验。部署状态声明须来自受控集成端对固定场景和作业期间外部物体出入的约束；未知开放环境仍走现有路径。允许在这一条件下使用静态实体地图解释原本由手自身挡住的已清通道；仅在已注册覆盖、没有外来侵入证据且工件/手的绑定持续有效时沿用。多姿态无运动场景可在独立校准夹具补原相机覆盖。记录实际射线覆盖及误差。不得从运行态仿真物体位姿、接触或渲染分割 ID 生成在线净空。碰撞监护与事后独立评分继续读取原有授权信号。
- [ ] 在空台图和同帧深度之间识别新增的近表面（含接近路线的外物），用当前真实视觉工件和实测关节/指宽投影仅解释已知体的可见面，在其遮挡背面保持登记条件，不盲删整块掩模。校准变化、陌生占用、目标/区域身份不符、边界外移动、手外近回波和违反工作区前提均触发原生拒绝/停稳。以真实插入实体的近邻障碍和错标定作负控，以正常台和带手自遮挡的实际源作正控。校准及注册占用、现场新增占用、遮挡、许可指腹终触四类证据分别可冷读。
- [ ] 静止无动作时，用预登记的通用有限顺序计算当次可行对象局部抓点：优先固定腕中心和双侧稳定搭接，其次静态几何可行的有限切向偏移（沿现有 1 mm 格按向外递增、正负固定次序），用同一实测手盒/板梁/掌/全臂/桌面/放置区域和运动轨迹计算可安全抵达的本体与负载路径。缓存仅含登记几何、控制分段和被选物体系偏移；初次全搜计入总耗时，另采新鲜帧后再签发。新帧身份、真实测量轨迹起点、抓点及装配仍须满足预选适用区。静止首个候选可证者即可返回，无需枚举 303 项才走控制。材料允许校准同原技能配置的短段跟踪及安全停距，足够余量时接受；轨迹初始位移/制动、自遮挡、持物体全盒、放置与退出逐段验证。单步不越可停边界，发生偏差先触发原有停止。
- [ ] 每次反馈只对同一注册目标执行原生采图、ROI 上的可见 ID/区域测量（必要时在截止内回退现有完整检测）、一条选中路径的局部扫掠/异常检测、源新鲜度、修正量、原只读 IK、签发与实际适用的原安全门。初始/跨阶段绑定同 frame/lease/generation/calibration/offset，禁止后续在原批条下换点。按原感知角色兼顾载物转移、PLACE、RELEASE、RETREAT，依现有协议检查当前目标区。在 GuardedClockEpisode 的正常注册 handoff 和原 MuJoCoVisualServoController 的 sample/IK 外层以单调钟记总时长、原有模拟步预算和动作墙钟；不把采集、图拷贝、钻取 ROI、判据或 IK 移出计时。同帧可复用解析输出。正常反馈≤100 ms；过期、耗尽、未知、误绑定、异常占用在下一命令前触发原保护。高位安全静止时已有一次重观可用须另计，用新采集重新绑定；人为失标不是正常实跑前置。

## C　原生接入与执行

- [ ] 先测试回归 RED 并记录，再修实现。验证身份单/双标、区域、碰撞与自遮挡正负，未实测角差、非法偏移、旧帧/租约、超过 100 ms、移入异物、路线中点碰板等反例；通过表示能拒绝反例且可接受真实正例。依次做原生无动作预检、独立训练夹持/监护和训练八阶段。调试允许同训练摆放使用新 attempt/代，所有中断记录。保留真实第一拒绝、那一步完整 RGB-D、关节、接触、原动作时钟、窗口及可独立读回事证，针对本计划内已预见的遮挡、支架、固定腕接触、扫描时延依序调整，再以新代重复训练。出现新根因、超范围或计划外失败，保全原状，由 Astra 新一轮计划处理受影响部分。
- [ ] 运行环境为现有项目主目录 .venv、工作树 PYTHONPATH、MuJoCo EGL 及同一设备独占锁；确认真实可用原生 context、既有私有生成代和冻结清单，写单独私有 evidence 目录。复核本计划全部 SHA，任何漂移先区分已许可新代与输入变化。执行者先记录所用解释器、包版本、实际导入文件/生成代 SHA、相机配置、CPU/线程与设备。顺序产生 allocation → exclusive claim → 实际 8 个技能 → audit → seal → 独立进程冷读与评分。训练顺利即跑预登记独立开发评估，无需额外正式名额。
