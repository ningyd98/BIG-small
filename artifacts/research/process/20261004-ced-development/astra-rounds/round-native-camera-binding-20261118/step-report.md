# 相机绑定加固验证结果

235 项限定 CPU 测试通过。唯一一次完整零 API 重放在 `LIFT` 的物理步 2480 因帧新鲜度保护停止，worker 为 `FAILED`。实际模型调用、生成和 API 请求均为零。余下 `44102`、`44103`、`44104` 继续冻结。

- 47 项冻结输入 SHA256 全匹配。持久 CPU RED 使用 fixed-02 冻结画面及真实检测器，复现了普通回退错误接纳跨步错机位帧、重封包后错误标定取得接纳，以及错误朝向、时间推进或倒退、重复 ID 和大端哈希缺口。最终 RED 为 7 个预期失败、3 个对照通过。初始测试将一个原本因严格角点不足被拒绝的中间帧当作正例，已改用真实通过的新帧，原测试日志也保留。
- 每次回退都在测量提交前检查请求的完整光学外参、同组仿真时刻和技能内未使用的观测 ID。显式 MuJoCo 组件重新计算参考和采集帧的小端 20 个 float64 标定摘要。后端命令游标检查只处理新命令，保护组内物理步、仿真时钟和关节命令。候选生成、几何阈值、正常姿态控制、已有非平面作用域、两次备选与 100 ms 限值保持。
- 重放停止前的 251 张伺服帧均通过标定摘要复核，唯一已完成换视角组通过完整外参、相同仿真时刻和命令顺序核验。最后有效控制样本在 2472，所有有效采样和 IK 的最大耗时为 50.652 ms。2480 只记录两次保持及紧急停止，无相机移动或新关节目标。
- 2480 帧的 RGB、深度和有效掩码与此前成功的协议重放逐字相同。采集 UTC 为 `00:57:28.132878Z`。深度文件的 mtime 距采集 10.278 ms，有效掩码距采集 122.014 ms，元数据距采集 122.819 ms。归档发生在活跃 TTL 检查前。原始证据支持一次约 111.74 ms 的归档间隙，尚未确定延迟来源。帧或时限没有改写，未消耗第二次完整重放。
- 真实 `fixed-01` 失败、`fixed-02` 与 `fixed-03` 成功、`44101` 严格几何安全停止，原记录保留。实际总消耗仍为 4 次云请求、16 次本地生成。修补前后各 50 个源码文件均按实际字节保存与复核，本次生产变化仅 `servo.py` 和 `sol_molmo_components.py`。正式研究 `NOT_ACCEPTED`，新增合格分组 0，真机 `NOT_STARTED`。
