# PLACE 当前视角恢复结果

已用解析候选恢复原放置失败边界 4328。完整零 API 重放在物理步 4336 因新的标记深度平面性拒绝停止，执行了 6 个动作，独立物理结果失败。余下 6 个真实运行仍暂停。

- 41 个冻结输入的 SHA256 全匹配。最小接线将提案刷新扩展至各自已经完整通过的 `MOVE_TO_REGION` 与 `PLACE` 帧，并将首错处理绑定到原 servo 可恢复错误集合。共用原首备选优先顺序、已有候选网格与排序、去重、两次切换和 100 ms 上限。七个预期 CPU RED 分别覆盖放置未刷新及三种区域首错未采用新次选。修后 169 个限定 CPU 测试通过，3 个渲染测试按范围不运行。
- 使用一次重建复制 4328 的独立物理状态。预登记的第一候选 `[0.7024868398022378, 0.2973738129037405, 0.8]` 同时通过严格标记及 4 个区域角点。次选 `[0.20043512648627318, -0.20430134203838068, 0.8]` 有 4 个区域角点，标记未观测。各仅一帧，从同一冻结 RNG 状态采集。诊断结束后未继续控制。
- 唯一完整重放重新采集实时证据。4328 的总览因区域边界深度不清晰被拒绝，原首备选左视因标记未观测被拒绝，实时解析候选新帧随后通过标记与 4 个区域角点。4328 完整采样和 IK 耗时 89.98 ms。两次换视角在同一物理状态，目标按控制网格在 4331 下发。
- 4336 的首帧沿用同一相机。标记中央像素 `[146,91]` 的 3×3 深度中位数为 0.81214559 m，距四角拟合平面 2.040551 mm，超过原 2 mm 限值。四角残差绝对值不超过 0.160 mm。区域离线严格几何仍有 4 个角点支持。真实控制路径在标记非平面门立即停止，命令序 700–702 为两次保持和紧急停止，无新相机动作或关节目标。
- 物理抬升 0.1056172488 m，持物 3.1875 s，稳定放置 0 s，无安全违规。两次本轮运行均只调用协议替身，每次使用归档 4 条 Molmo 与 1 条 Sol 响应，实际模型载入、生成和网络请求为零。原真实 `fixed-01` 和之前三次重放的失败全部保留。正式研究 `NOT_ACCEPTED`，新增合格分组 0，真机 `NOT_STARTED`。
