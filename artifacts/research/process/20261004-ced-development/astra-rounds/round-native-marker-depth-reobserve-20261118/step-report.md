# 放置标记深度重观测结果

显式放置重观测通过。唯一完整零 API 重放完成了 `PLACE` 和 `RELEASE`，独立物理评分成功，但在 `RETREAT` 的垂直撤离段触发原默认硬停止，worker 仍为 `FAILED`。剩余 6 个真实运行继续冻结。

- 28 项冻结输入 SHA256 全匹配。原 4328 帧仍通过标记，原 4336 非平面帧仍为 `UNKNOWN`、无可用姿态。原 2 mm 深度门、区域、TTL、两个备选和 100 ms 限值保持。恢复开关严格布尔并默认关闭，当前仅显式组件 MuJoCo `PLACE` 传入开启。
- 八个预期 RED 覆盖启用路径、严格作用域和持续或重复坏帧，一个默认拒绝正控制通过。最终 185 个限定 CPU 测试通过，3 个渲染测试按范围不运行。深度、朝向、身份、标定、时序或区域硬拒绝仍直接停止。重观测只使用同技能最后已接受帧和已绑定提案，拒绝帧独立记载哈希和原因。
- 4336 的新重放仍取得原不合格帧，中心残差 2.040551 mm。由上一有效帧生成的提案使相机实际移动约 4.34 mm，新配对帧中心残差 0.546918 mm。两帧仿真时刻一致，命令序 700 切相机后才在序 701 发关节目标。后续 4912、5176、5232 还完成了三次相同错误的重观测。全链已接受采样和 IK 最大 85.28 ms，`PLACE` 在 5406 完成，`RELEASE` 在 5670 完成。
- `RETREAT` 的垂直撤离子段从 5958 开始，冻结目标 z 为 0.16 m。最后有效采样在 6510，标记中心距平面 −0.402 mm。6518 时标记中心 `[154, 94]` 的 3×3 中位深度为 0.90563965 m，距四角拟合平面 2.248470 mm，四角最大残差 0.116521 mm。区域离线严格判定仍有效。撤离维持默认策略，该步只记录两次保持和紧急停止，横向撤离未执行。
- 独立物理证据为抬升 0.1056172488 m、持物 3.1875 s、稳定放置 4.5083333333 s，无安全违规。8 条动作记录包含未完成的撤离，终局断言失败。4 条 Molmo 和 1 条 Sol 均来自冻结协议内容，实际模型载入、生成或网络请求为零。原真实 `fixed-01` 和此前全部重放失败保留。正式研究 `NOT_ACCEPTED`、新增合格分组 0、真机 `NOT_STARTED`。
