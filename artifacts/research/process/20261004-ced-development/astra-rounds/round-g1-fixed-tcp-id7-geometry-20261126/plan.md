# G1 固定工具位姿下的标记遮挡筛查

Astra 模型 gpt-6.2-astra，基线 b8de4cf1d48284d81fbf5391c58b66995d0f0d69。原 B 的 9 张 RELEASE 静态复采均缺姿态资格。原几何筛查 ID7 可见点为 421–436/1024，主要遮挡来自 link2 与 link3，ID8 为 1024/1024。t02 当前门第 1512 步缺独立有界载物姿态。待验假设为七轴局部余度在原工具位姿、原夹指、原工件、标记和相机条件下缓解遮挡。

1. 按摘要恢复三条 B 轨三个登记步，以及 t02/1512。B 重用原复位及配对输入核对。t02 绑定相机及同曝编码器、台面、工件和原 TCP，另以原步末编码器核对稠密物理自碰距离和接触类别；标明步末状态与同曝几何的缓冲区别。逐态检查原位姿与基准射线，缺失则保留阻塞。
2. 固定基准六维 TCP 雅可比 SVD 单位右零向量中绝对分量最大的轴，平局用较小轴号。相对基准冻结 −6、−4、−2、0、2、4、6 度网格。两方向由零向外，固定选定轴，仅校正其余六轴。首个求解失败后，同向余格保留未取得状态。最大 40 次迭代、轴校正每次上限 1 度、各轴最大总偏离 12 度，严格保持关节限位、位置残差 ≤1×10⁻⁷ m 及旋转角残差 ≤1×10⁻⁶ rad。秩阈值为最大奇异值的 1×10⁻⁹。
3. 每格用原 backend 自碰对、运动臂对台面/目标区/工件/载板及夹指禁碰对检查。静态候选禁碰距严格 >1 mm。原许可接触只含实际绑定的指–工件与工件–台面；只允许基准已见具名对，固定接触不得劣化超过 1×10⁻⁷ m。无法得到正几何界、模型距离未可靠或出现新接触均保留拒绝。胶囊到盒在引擎返回零时可用形体投影的严格正分离下界；坐标轴、盒轴、胶囊轴和叉积均只提供充足条件。保持原装配，自碰筛查不对连续轨迹作结论。
4. 每态报告两张码的 32×32 面点首次命中、遮挡几何、实际 6×6 格心、内侧编码与字典四方向相容性。另按冻结对侧板的同样像素和深度条件复算理想边缘列，忽略颜色条件，独立报告两边各 5 列的几何前提。曝光原图不随姿态变化。所有增益均相对各自零偏移。记录候选空间、有效格数、每格拒绝及任何码字/板边证据。原相机图像只有既有记录。
5. 用不同进程复算零偏移、源哈希、可见性、位姿及碰撞和比较。负控使用可见目标换成错误首交面、离轴姿态误差和碰撞负控。1 轮十态 70 网格行，非零格至多 60、校正总次数至多 2400。固定网格不扩张。仅用静态 MuJoCo 工作数据与射线，原件只读，没有动作、积分、渲染、曝光、运行复位、整机训练、独立评分、留出、正式、硬件或云请求。几何可行性不授予原生检测、RELEASE 或轨迹资格。
