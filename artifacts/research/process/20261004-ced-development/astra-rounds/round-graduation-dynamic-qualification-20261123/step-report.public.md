# 固定抓放与动态视觉实例

本轮预先登记六个固定夹具工况和一个独立 r593 组件工况。七个开发身份各用一次。固定夹具采用预设 TCP 目标，视觉组件从实际图像重建候选目标，两个入口的输入与物理动作单列。联合清单先于两边首次实例化写入。[联合清单](allocation.public.json)

| 原固定工况 | 实际物理步 | 实测 |
| --- | ---: | --- |
| 抓取、移动、释放 | 5,013 | 7 个技能成功返回。原阶段判分通过，独立逐步评价为 SUCCESS。最大抬升 104.614 mm。 |
| 无接触抓取 | 239 | 未满足接触条件，返回 NO_GRASP_CONTACT。 |
| 不可达目标 | 0 | 拒绝该目标，位置误差约 2.038 m。 |
| 运动超时后保持 | 239 | 超时前运动 119 步，保持 120 步，其间 TCP 漂移 0.239 mm。 |
| 急停 | 750 | 停止后提交新运动没有推进物理步。120 步保持中 TCP 漂移 0.971 mm。 |
| 空手放置 | 0 | 空手放置被拒绝，未推进物理步。 |

固定正控的独立读回覆盖从 0 到 5,013 的全部 5,014 个采样。LIFT 返回后第 2,584 至 2,704 步共有 121 个采样，跨越 0.5 秒，全窗双指接触，物体相对初始位置抬高 81.516–83.413 mm。RELEASE 后第 4,773 至 5,013 步的 241 个采样跨越 1 秒，夹爪张开、指尖均脱离物体、物体投影均在目标区。两次独立评分输出逐字节一致，两段窗口另外直接枚举核对。固定几何与同一场景限制了这个结果的适用范围。[原阶段、逐步物理评分与否决项](physics.public.json)

r593 开发实例在第 0 步和第 120 步均能由真实 RGB-D 解出候选目标。注册参考帧与随后的 MOVE_ABOVE 帧 ID 不同，墙钟相隔约 0.467 秒，但模拟时间相同。原跟踪器在动作绑定时返回 `capture_not_new_and_monotonic`。工况实际得到 5 帧、2 个物理时刻、121 个物理状态，动作、PRE、Shield 和控制反馈均为 0，后续七个技能未执行。两次独立评分逐字节一致。该记录定位了开发适配器的采集时序问题。[r593 原实例](vision.public.json)
