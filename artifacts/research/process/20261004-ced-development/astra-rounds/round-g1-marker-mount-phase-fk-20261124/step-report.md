# G1 阶段姿态校验修复

首次阶段只读入口在创建输出目录前拒绝了正确登记。实际位姿恢复接口给出 TCP 位置、物体中心及旋转矩阵三项残差，原图像复现工具还包含三项像素和深度比较指标。新增入口错误地要求两个字段集合完全相等，第一个版本的测试也用六项数据构造了正例。[初次失败和精确字段](original-finding.public.json) · [Astra 校正计划](plan.md)

用真实 MuJoCo 模型和 `mj_forward` 复现了三项残差为零时的错误拒绝。四个预期失败保留。修复后按确切的三个字段比较冻结门限，含上界，独立评分再用保存的数值重算判定。超限、缺键、多键、错误门限、负值、布尔、NaN、无穷及几何不符皆受检。另在真实封存文件副本上反转一项姿态判定，保持重建数值不动，读回拒绝该矛盾记录。
