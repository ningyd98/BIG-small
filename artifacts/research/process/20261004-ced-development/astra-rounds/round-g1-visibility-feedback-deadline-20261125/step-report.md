# d02 实时视觉反馈修复与复测

低位双标的第一个开发试次在上方移动的第 672 步停止。这张 RGB-D 仍给出了可用的 ID7。控制器实际记录从反馈取样到目标检查和逆运动学用时 104.241 ms，超过 100 ms 限时。原生 70 个窗口的 P95 为 52.780 ms。逐项核对表明，超时帧从图像就绪到 SafetyShield 记录完成为 73.600 ms，其中格网算法处理了 48 个没有通过亮暗证据检查的 ID8 候选。[原生记录](native-d02-baseline-times.public.json) · [时间分段](native-d02-window-segments.public.json)

修复保留每个候选的拟合次数、印刷格、亮暗裕量和留出残差条件，把同一码的独立拟合合并计算，对可能通过和接近门限的候选仍做完整验证。两版程序在 778 张旧帧、75 张 d02 帧及 20 项对照上的结果逐项一致。单独复测 30 次，原超时帧的像素处理从中位 70.124 ms 降至 30.707 ms。五个独立进程共 350 次顺序反馈，候选最慢 31.022 ms。开发预检两次复位、零步通过。[语义核对](semantic-equivalence.public.json) · [耗时与样本](pixel-timing-summary.public.json) · [预检](candidate-preflight.public.json)

同一历史摆放 d02 的新开发实例已真实执行。原超时步 672 的完整控制器窗口为 63.948 ms，上方移动通过。122 个完成的反馈窗口实测 P95 为 61.868 ms、最大为 74.995 ms。机械臂随后在接近的第 1088 步收到身份歧义，停止在闭爪之前。终止帧在视觉更新阶段被拒绝，控制器没有为它记录完成时长。[复测原生时间及停止帧](new-d02-native-times.public.json)

新试次产生 130 张 RGB-D 和 1,089 个物理样本。原始轨迹表明物体最大抬升为 0 mm，两次盲读及独立评分一致，完整抓放成功 0/1。连同此前在第 672 步超时的试次，d02 历史开发共两次尝试、成功 0 次。单标与双标的正式四对试验维持原计分，四个新开发摆放尚未生成。[独立动作与物理读回](new-d02-outcome.public.json)
