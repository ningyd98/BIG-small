# G1 B03 左指撤离初始净空的逐角点方向下界

规划模型 gpt-6.2-astra。基线 2142e5050e65f037f92f87b219497d9df07895a7。

P/Q 真正 RELEASE 连续 31/31、物理 241/241，预登记末 DWELL 的冻结撤离制停净空下界为 −5.056/−51.817 µm，同为左指/方块。假设用原证书对每个实际局部角点单独传播误差，可提高这一对的初始分离下界。原运动拟合的 pair_gap 来自 mj_geomDistance，只有引擎返回 0 时才用非负 SAT 回填。沿固定轴的时间下降不是原闭合量。

1. 从真实生产者、冻结 fit/资格回执、原 RETREAT 训练轨迹的 normal、limits 及 9×241 停止档核验 paired gap/engine gap。对两个纳入原 RETREAT 拟合的完整轨重算目标对原闭合量和所有配对包络，重现 1.25 倍最大降幅加 0.75 mm。原验证只读已公开绑定回执，不开启新保留组。正的投影下界小于等于真实凸体分离距离，同时属于未旋转机器人 OBB 的真实 SAT 候选。以冻结轨逐行检查其对原混合记录的保守关系，发现反例立即停止继承闭合量。
2. 仅取 B/P/Q 各自 OPEN+480 末帧的实际 DWELL，当前曝光及 q/f 与已经关闭的 RK4 和独立原物理档绑定。白名单投影复用先前精简 RESET 身份，禁止在预测中读取在线许可、分组映射、接触和真实工件姿态。当前身份、帧及光学证书按冻结 rigid_pose 重算。B 缺姿态须继续拒绝。P/Q 用原分析 FK 构造左指 OBB，按三个确定的面轴各取正负六向。工件真实局部角点 v 的名义投影减冻结 directional_error(v,u) 后取最小，再减该方向已知左指最大支撑。取六向最大为初始下界，扣保守浮点余量。禁止使用任意世界轴、标称工件轴或叉乘轴作为改进，禁止搜索帧、阈值、方块或配对。
3. 只有初始分离严格为正且混合量审计通过，才扣一次原左指/工件闭合量作为附加下界。较原对更强时仍需原所有别对、连杆、配对时窗、域和严格式体积核验。台面许可的条件性情形另行记录。原单体与全局最小值、限制对、六向和限制角点均记录。等号拒绝。只对这一对、同一 B03 RETREAT 必要前置做研究影子调用；从不修改或签发当前真实在线门。
4. 两次独立三槽 CPU 盲读一致后解盲一次。用真实锁定工件态测试六向全部角点是否落在证书范围、初始下界是否低于实际 SAT，比较定向下界与原物理量。合成无误差、偏心角点、旋转误差、右左符号、最优轴择优、接触/穿透、错证书、时序轴切换及闭合量篡改对照。失败保留原件，停止本轮。无新的形状、暂停、偏移、原积分或候选搜寻。

若最小值转正，只证明冻结开发证书的体积/净空必要条件，仍缺真实原生 RETREAT、在线 RELEASE/PRE 和 LIFT 前置。新增曝光、GL、积分、控制、整机、正式、独立正式评分、硬件或远程均为零。
