# grid‑04 载物参考 EGL 首次构造

gpt-6.2-astra 制定，基于 `6102b510224c22cdf1ce9ed78d5f2bdde6e35583`。两次真实首拒采图至净空门分别为 102.780 和 103.655 ms；同期载物参考在发现 unresolved pixels 时才构造。旧 B03 预建实验只涉及机器人深度参考，载物参考没有投影。检验原载物参考在同一 episode 线程提前构造，是否减少原首拒帧的局部计算用时并保持所有像素归属不变。

1. 固定封存的 2384 原帧、原配准和同曝光编码器。同一原 EGL、GPU、驱动及共享非阻塞独占锁下，三对交错顺序，每个条件用新进程和原 `CarriedSurface`。对照保留 `LocalClearance.changed_surfaces` 的懒初始化。另一条件只提前构造资源，零预投影。两组每次根据该帧光学位姿重做真实载物 RGB 和深度参考；机器人参考用同一历史封存数组，两组相同。
2. 记录构造总时、MuJoCo 模型和 EGL renderer 构造、场景更新、同步 RGB/depth render 和读回、逐像素判定与局部起止。GPU 投影用原 Python Renderer 的同步像素读回。真相机、积分和运动入口设拒绝哨兵；总预算六次载物投影、十二次底层 render，零新原生图。每次同线程释放。原判定 `checked=2, explained=0`、未知像素与同一参考 RGB/depth 数组必须等价；出现偏差保存并停止，无重复。
3. 只报告局部归属的时间，提前构造费用单列。若配对下延迟下降，仅给出进一步同会话应用的依据。真实相机、完整 ActionClock、IK、保护和下一动作的 100 ms 资格仍未知；原光学拒绝与正式分母照旧。六个独立进程各一次，零积分、整机、正式、评分、硬件、远程。
