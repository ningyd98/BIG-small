# 无渲染退出与原基线读回

原 A01 在第 5637 步封存物理原件后，退出按需采图上下文时进入默认渲染路径，因缺少 GLFW 显示环境退出 1。原回执中的 `complete` 表示物理窗口已经写完。当时退出仍未成功，渲染器未产生 RGB-D。重新检查原件的 gzip、918 条命令、502 个归档状态、时钟、逐指净空和原 RETREAT 边界后，保留这条物理基线用于成对比较。原失败、脚本、登记和物理轨均按 SHA256 封存。[恢复计划及原件散列](plan.json)

恢复脚本在记录和关闭原生轨迹后用私有终止单独退出按需上下文。原生后端在此路径清除按需标志，正常关停成功后才发布完成回执。独立零步检查覆盖了原帧对象、同名但被替换的空帧、不同终止异常实例，以及正文、轨迹关闭和关停错误。四种错误均原样上抛且未生成完成记录。剩余 A02、A03 和三个 B 均走过修复后的路径。[零步验证与来源](../round-g1-release-empty-frame-preflight-20261126/step-report.md) · [恢复登记](recovery-registration.json)
