# G1 原局部门实时预算的分项与等价试验

规划模型 gpt-6.2-astra。基线 `c7c398ce18c53faca9dba9c326bde14a3679c330`。

原 B03 Q 在末 DWELL 与同刻新图上获得条件性局部 CLEAR，8+240 净空下界分别为 +0.147026 与 +0.685864 mm。分别耗时 164.466 与 187.140 ms，已超 100 ms 且不含 IK。原图封包分别用 14.06 和 56.90 ms，原局部检查分别用 99.88 和 82.03 ms。两个独立 preview 各自冷启并关闭资源。原在线 owner 的证书随 episode 保留。重复完整状态摘要在曝后路径还遍历并序列化所有命令，结果当时只取积分摘要。以这两项为首轮可检验原因。

1. 校验 plan.json 所列输入、原运行时及私有封包成员。先只提取 `mjSTATE_INTEGRATION` 的原小端 float64 字节摘要。完整状态摘要仍用于命令或前缀契约。初始化一次同一 episode、asset SHA、相机和 GL context 下的原 RobotDepthReference。在原 reset 和资格绑定后、实际首次反馈前预热资源，每个需要参考图的真实曝光仍用自己的同曝光编码器重算投影。两个 preview 的证书、角色、已见帧和历史保持独立，各自借用、统一关闭资源。跨 episode、异 GL context 及失败后复用一律拒绝。不得复用深度结果。原装配、相机、标记、求解器、判据、控制器及 ActionClock 不改。
2. 先在封存输入上通过等价性。独立重建 31 张真驻留历史，并重算两个端点全部结果。除实测时间及新计数器外，逐项完全一致。验证积分摘要与老完整函数的积分字段完全相同。拒绝错误 checksum、同 tick 独立帧互换、错编码器、跨场景、跨 episode、错身份和角色。以冻结 LIFT 首拒输入检查共用路径的原近面拒绝或原体积拒绝，缺原参考深度时标为该项无法像素重算。纯 CPU 计时每种实现在两个端点分别 1 次预热与 10 次观测，交错顺序、固定线程。每次从自己的驻留历史副本和新的证书状态开始，可用封存投影做 CPU 回放；输出全部耗时样本。失败先封存，停止实拍。
3. 等价性通过后只允许一次与原 Q 完全相同的隔离路线。保留所有原始证据、物理/编码器见证和原计时终点。由实际快门开始分段记录 RGB-D、封包、同步身份、marker、姿态与历史、参考投影、当前深度归属、交接域及体积、科学判定和审计调用。收口时分开记录引用资源创建及关闭耗时。凡阻塞下次反馈的同步工作仍计入。原图、两张当前图或不同角色间不得共享像素、marker、姿态或归属结果。若原两项仍不足且分段定位到轴深解码，可另登记一项单帧、单次作用域只读解码复用。原解码顺序、dtype、阈值和所有身份验证保持。
4. 本轮最多一次真 EGL Q reset、5565 步、43 次原相机请求、2 次实际机器人参考投影、0 次载物参考投影，禁止重跑、补采和 RETREAT。报告两次各自与同角色旧口径耗时对照。任一超过 100 ms 维持未达标。即使局部两次均通过，仍需原真实 owner、Shield、IK 到下一命令或积分边界的完整反馈。原 LIFT 的未归属近面与载物制停体积首拒维持原判，不能由时间优化解除。新增整机、正式、独立正式评分、硬件、外发均为零。
