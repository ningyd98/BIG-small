# B0 历史双图在现行发送链中的回放

47 件历史文件的长度及 SHA256 全部一致。四个历史 RGB-D 与实例帧由原读取器恢复。隔离网络命名空间内，实际运行现行 `_attempt` 到 HTTP opener 的全部代码，只有 opener 用内存替身。四个历史请求的现行序列化字节与原文件逐字节一致，替身分别返回四个历史真实响应的原字节。四组解析、目标命中和目标区命中均与历史一致。四条测试账本记录来自替身。新增真实 HTTP、原相机曝光、当前付费探针、实际 B0、正式 G2、独立评分及硬件均为零。

独立冷读重新核对八个历史／回放 wire、布局和槽位摘要。原名义探针独立消费者仍拒绝用旧角色源码签发现行探针；改一字节的私有副本被原独立读取器拒绝。重复位置、第五次、错误路径、错误字节、完成或预扣后重启均拒绝。首次隔离检查因沙箱禁止 netlink 接口枚举未启动回放。改为同时核对内核网络命名空间身份及作用域内的 `/proc/net/dev`，再保留 socket 连接禁止和无真实 opener。

单独的实际入口与前一版共享原探针路径、工作区和 EGL 锁。启动及每次请求的有序预扣槽位分别排他创建并同步落盘。当前只用历史替身验证发送边界，实际入口需模拟双图外发明确授权和环境审批，尚未启动。480 个 B0 分配均为 NOT_EXECUTED。

现行研究账本及 B0 selection 的现有两组回归最终 36 项通过。普通沙箱首次阻止了两个临时回环 HTTP 测试创建 AF_INET 套接字，34 项通过。本地隔离命名空间只启用回环接口后重跑，36 项通过。测试字节只传给临时 127.0.0.1 服务，没有实际云服务或模拟图像外发。
