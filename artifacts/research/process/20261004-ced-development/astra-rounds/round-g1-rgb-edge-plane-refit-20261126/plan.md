# 四列原 RGB 锚点的配对平面重拟合

Astra 规划模型 `gpt-6.2-astra`，基线 `2f9148cceb271a406ee27b363800cc9ead2ad3ed`。固定 RGB 线使用 ID8 原局部平面时，2,502 个窗口的 548 个及两个自然情况中的一个超出原误差界，所有 549 个都有物体 X/Z 轴间俯仰越界。本轮只检验省略了原远面重拟合是否解释这些误差。

1. 逐项核对冻结登记和 523 个源图。复现同一图、原状态、原位置、现有强弱侧与四列窗口、度量线和初始旋转。只进行冻结的 2,504 个配对。原整套段的身份、拒绝等先逐项复现及保留。
2. 对每个已经原色深通过且被保留的锚点，只添加同图原代码的 (x, y−2×sign) 近面有效轴深，以及原 ID8 中部的有效实测点。按原顺序反投影，调用原 `_fit_plane`，保持世界锚点与物体锚点杠杆臂。把原 RGB 前向量投到更新平面并按原叉乘重算旋转。扩展平面无法拟合时保留初始结果并单列，退化或输入异常立即拒绝。禁止新列、阈值调试或使用真值选点。
3. 在原 `id8_opposite_edges` 未裁剪正控上，用原序、原内点与全部外点独立重建原姿态，核对方法、锚点、中心及旋转。保持 A/B 和 t02/2112 拒绝。两独立 CPU 预测拒绝读真值及已评分输出，结果先逐字节核对，再由标签进程评分。原基线、登记或验证失配立即中止并封存。
4. 报告所有配对的原/新锚点、转轴、偏航和角点误差，持续缺界、恢复、新越界及重拟合失败。任何剩余失配都不允许宣称完整恢复。即使冻结集合恢复，自然匹配也只有一个非目标轨，不能触发 1512 关系回放或在线资格。新增渲染、曝光、积分、控制、整机、正式仿真、独立正式评分、硬件和远程调用为零。
