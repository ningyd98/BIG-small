# t01 的 5.5 s LIFT 首拒光学诊断

gpt-6.2-astra 制定。执行基线 `92cb8207c6e67a7811cea92a0c83e382ce6f716c` 已包含上一轮首拒报告。用第 1840 和 1848 步的原始曝光检查近回波来源及原相机是否能区分固定异物。当前无运动晋级资格。

## 原件与假设

1848 的 `LIFT/feedback` 只留下像素 `(173,130)` 未归属，归档世界点为 `[0.42298,-0.05676,0.00888]` m。实际原帧为 `0197.json`，同刻 `0198.json` 是 terminal 图。工件底距台 2.240014 mm，仍有双指接触。原首抛为 `unregistered_near_surface`，采图至门结束 112.458979 ms，超过 100 ms，缺成功的完整采样及 IK 时间。此前 27 个成功反馈为 40.961–53.597 ms。可能原因包括同一像素内的表面或遮挡边混合、异物近面仍与读数相容、CPU 射线和 GPU 采样的差异。

1840 已放行窗口的独立制停延迟 0 出现 ID8 板负 Z 包络欠覆盖 0.162402 mm。现有 209 个分支来自候选实际轨，1840 的原件不可当作 1848 的实测制停。旧 t02 同视角有针、无针深度逐值相同，其针与旧工件首次交于 176/240；不能将旧异物的位置或相交时间套用到 t01。

## CPU 第一阶段

1. 重验计划内所有输入 SHA256，展开实际代际、标定、病例分配、采集/局部判断封包与逐帧索引。逐帧绑定 scene、episode、曝光编码器、时钟、文件、校验和以及 LIFT/feedback 角色。核验原回执和 1840 制停分支的 trace 及源文件关联。
2. 用原图、原标定、分配几何、同期机器人包及原合法历史复核判定。预测环节隔离工件真值、接触和制停档，在封存后才开放几何输入。完整原光学门需 EGL 时，沿用封存在线判定及已有冷像素读回，单列本轮 CPU 的轴深、原空台深度、测距误差、近面计数、四邻域和世界反投影核对；记录完整原门未重跑。
3. 必须拒绝同刻 terminal 替换、错误像素约定、错眼、陈旧编码器以及错标定。原 t02 光学反例只读，保留原结论。

## CPU 第二阶段

4. 用原 XML、相机、完整资产树按具名关节、双指及工件自由体复位 1840 和 1848，允许 `mj_forward` 与 `mj_ray`，禁止积分。核对相机眼、手性、内外参、轴深定义、时钟，以及独立 TCP/工件等可核姿态，位置差不超过 1e-9 m，旋转 Frobenius 差不超过 1e-9。逐一记录缺少直接参照的实体，若能影响光线或遮挡则不能进入曝光。
5. 固定像素中心、四角、4×4 子格中心，记录首交、可验证遮挡顺序、法向及轴深。离散采样比例不代表 GPU 采样。用整个像素的连续视锥和原误差带核对可能占区，缺完整覆盖则仍为 UNKNOWN。对同一个视锥与已封存 1840 制停姿态实施独立逐步投影，报告当时离散可证交集和姿态缺口。保留 1848 制停没有实际见证的事实。
6. 若能选定同一世界位姿和原已验证实针模型，在改动原机器人、工件、相机和台面前提之外签发固定夹具登记。针须与 1848 的待辨占区相交且装配/支撑可证，在 1840 则须有同一针对应的明确阳性预测。冻结 XML 差异、材质、位置、原光学覆盖、选针规则与 CPU 预测。前置不够即结束于 CPU。

## 条件静态采集

仅在 CPU 两阶段和原 320×240 相机、原四倍采样、原标定、原设备环境、零积分复位、针装配及暴露的阳性对照均可证后，独占 EGL 进行一批静态复采。两时点和两种子先各采原场景，共四张。历史与新基准解码 RGB、有效掩码须一致。沿用 A/B 原已登记平均深度偏差绝对值 ≤0.05 mm、RMSE ≤1.60 mm、绝对差 P99 ≤4 mm；先复核该协议噪声和场景适用性，不适用则停止。再采两张 1840 同种子原针阳性，分别须在登记区域给出方向符合预测、严格超 8 mm 的轴深变化。阳性过关才采两张 1848 同针挑战。两布局同状态同 seed、不同布局只差固定针；历史逐曝光噪声未知。最多八次调用，失败占槽，无预热曝光、补拍、调针或更改原门。
