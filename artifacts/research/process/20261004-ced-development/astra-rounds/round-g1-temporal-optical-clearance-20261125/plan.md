# 原顶视相机时序净空证据

制定模型 `gpt-6.2-astra`。基线 `39faf2e7c41dd4ce9e378f151d864c74cd6593e0`，实际 t02 输入源代 `816ed631e9dd17b510d2853afda7995b87e210c6cf8259df799a8a4da6b491eb`。计划仅适用于已批准的受控 MuJoCo 开发场景。本轮验证的问题是：原相机在开工前已观测为空的固定空间，能否在同一实际隔离周期内消除后续已知手/载荷边缘的误拒，同时保持静止细针和动态入侵的原保护。

## 1　先取得独立的闭场凭据

- 原主计划 B 已批准受控场景注册、独立原相机空台观测、对外物出入的集成端约束与持续的当前帧检查。可建立新的诊断场景、原生隔离 runner 与测试夹具、软件开发计时和两个原训练摆放；现有独立整机槽、旧盲槽、正式和硬件均不启用。原相机/光学门、单像素未知停、运动和有载制动、夹持确认及 100 ms 时限继续生效。
- “闭场”应由实际模拟运行所有者的独立发行凭据证明：从该次采集前到相应动作，固定物理布局和无外部动态物的配置不可被其他正常操作修改，单一权威后端/进程、门控全部加入/删除/移动外物/重置/换场景入口，稳定场景代/epoch 和连续审计。若有可绕过的外部写入通道、可自由移动的未登记物体、未知入口、无可信 owner 或中途重新取得的锁，关闭整个历史例外。绑定实际场景实例、episode、相机/标定身份、原物理步与单调钟、装配、允许的可动物、有效期和失效事件。不能把 EGL 锁、XML 摘要、名义静态场景名、普通布尔变量或缺少变更日志当成实际隔离凭据。建图前即持有闭场凭据；另一次 run 的空台图只可作标定参考。独立夹具若需在作业台放回工件、移动手或换遮挡，必须绑定实际受控操作，登记影响区并作废受影响自由区；未见过的区域仍未知。首版优先同一真实开工状态多曝光，实现也可选择已注册合法静止姿态的补视，不额外消耗整机技能。
- 静止威胁包含开工前就存在的针、梁、块和接触前后不可预测移位的物体。建图中探测到新增近面，原门立即拒绝，未知占用不能被随后资料洗掉。只把得到系统保证的静止类空域按 epoch 继承。新异物、落下/脱落/穿入的东西、载荷滑移/破损、可移动不明物打破此前不变量，按现有保护停；中途允许插入的开场只用原当前门。相同的中途插入若同时能绕过隔离并且在前后图均不可见，则从现有观测不可判别，不能声称检测成功或继续以历史放行。实证不可判别即将能力限定在真正闭场。

## 2　先盲建逐射线自由区间，再与当前空间求交

- 校准空台、真实开工状态与待判运行的数据严格分离。多次调用原相机在静止许可边界采集**完整**新 RGB-D，按完整原生曝光钟与同期关节/手指读数封存。冻结标定误差、光心/深度轴转换、取样足迹、独立深度噪声和混合边模型。单姿多曝光仅减少可证明的随机项，不会增加几何视角或看透遮挡。预登记可复用的早期合法视线（例如已准入 MOVE_ABOVE 停稳处）须在当前 episode 的将来疑点出现前完成，不得读取未来帧或为消除本点增加未授权动作。
- 针对每个像素/射线与空间格记录可证自由的**深度区间**、来源帧、相机位姿/误差、边缘/遮挡和最近面上界/下界。到第一可靠表面的保守近侧才可能自由；遇到孔、亮度/材质/深度边、前景掩挡或采样不足保留未知。范围认证需实测最小威胁的可探测尺度与朝向，逐射线显式区分中心采样、像素边缘及子像素缝隙，不把一条中心线或稳定的下游桌面读数扩张成整锥。用误差向内收缩自由集、向外扩大待证体积；同视线重复取共同支持，依法合并具有独立覆盖的同一世界区域。在不同视线存在更近占用或矛盾时优先禁入。先预计算登记射线查找表/区间，运动中不调用真实场景分割、物体真值、接触或探针位置。正对像素间缝等不可观测的威胁若无法用物理闭场配置排除，明确保留该段 UNKNOWN。报告能证的空间和不能证的位置/深度范围。
- 在线只对**当次新帧**原门未解释近回波逐点复核：以同一曝光的机械臂编码器/FK 和已获当前视觉三维证书的工件/载板预测可见物理面、颜色/深度边、每像素可能的深度区间及关联误差，确定“能造成当前该回波/侵犯本段所需净空的未登记静止异物”可能占据的三维区域。只有该相关区域完整落入独立开工历史已认证的自由集合、闭场凭据连续有效、当前图正支持已知表面与距离、无其他未解释点或新入侵证据，才能把该像素重分类为具体手/工件表面并回到原几何、制动、夹爪及 IK 检查。不能只测中心点与旧空区有交集，更不能以工件轮廓、一帧颜色、对照图相同/远端颜色单级差或已知针坐标直接放行。失去任一前提，未解释一像素仍返回原拒绝。输出用到的实际早期射线、支持深度与误差、当前姿态证书、可能异物区域、覆盖缺口及首个拒因，供独立进程复算。

## 3　正负控与独立验证

- 先运行原 t02 时序与物理针/无针的 RED，封存原首拒及第 120、1504、2104、2112 步物理姿态的原始/成对曝光；训练可用已有反事实，禁止按该物理步、针坐标、像素或案例 ID 设计放行分支。预登记独立整组场景、曝光种子及校准扰动，严格按场景/物体与姿态分开拟合和盲验。开发 GPU 用于离线标定、渲染成对物理夹具及区间预计算。一次性对照标签由后端夹具管理；在线模块只读权限清单、原相机与允许的本体传感信号。在预测冻结后分别进行像素/深度几何和物理插针标签冷读，最后汇合。
- 正控为已锁闭场、真实无遮挡开工证据、后来手/载荷遮挡而仍应安全的真实路线，报告究竟哪些点达到判据。负控须保留原单像素真针和原硬障碍，增加未见位置/朝向/深度/颜色和像素边界、贴合载荷的异物、开工即隐藏、开工多帧重复遮挡、深度孔/丢帧、时钟重放/错代/错相机、全部历史来自另一场景、视觉工件身份不明及手外近面。设真实“开工后插入”：可监护入口变更应在下一条运动命令前撤销凭据并原机制停；若在权限缺陷下注入同像素不可见异物，隔离资格本身必须失败。另试隔离未建立或中途断开后图像依旧同样的情形，均禁止应用历史例外。开/闭场对照不能通过将所有图都拒绝来取得正控资格。
- 工具环境使用原 venv、MuJoCo EGL/相机与串行设备锁；验证实际资源上限、原固定摄像头、工作区和执行器，记录原生采集/决策/IK的单调时钟。区间可在启动时建图且须计入任务总预算；每次运动反馈计入采图、图像解码/传输、GPU 同步、选区、时序验证、原门及 IK，最大≤100 ms。每个耗时超限/错误发令都保留；实时预算不足即拒绝，不能改变采样周期或先发后审。
- 软件与隔离正负控通过后，只在实际证明闭场条件的原两训练槽依原顺序使用新 claim 和新代端到端训练。不得因为回放消除一个误报跳过原手/载荷走廊、针检测或 PRE。按原八阶段与独立门如实评分；若闭场只能在专用夹具建立，就仅报告该夹具的真针检出、无针误报、不可判域与实时性，整机该门保持原拒。留存原始失败、输入哈希、阶段报告、实际进度与范围，在分支按明确路径提交与核对三 SHA。新增根因、计划外失败或范围扩张暂停对应修复，先走下一 Astra 轮。
