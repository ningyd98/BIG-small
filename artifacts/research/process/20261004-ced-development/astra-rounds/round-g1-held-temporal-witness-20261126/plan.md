# Astra 计划 · 零滑移假设下的连续持物光学反例

模型 gpt-6.2-astra，基线 `de8cfc2ead2f5e528e044ab836c3e66f3374e650`。前轮五组首拒／CLEAR 的二十个原像素视锥均与完整制停包络相交。现检验连续持物光学误差界能否在乐观的刚性约束下排除首交面歧义。旧 t02 针别名、原门和 8+240 束缚不动。

1. 封存 plan.json 中五组十个端点的光学／曝光关节、机器人和原相机，以及原密采首面射线清单。按实际端点因果读取同一案、同轮、闭爪、已认可 held 的历史，原步差 8；错身份、乱序、缺包或开爪断开，重复曝光不得收窄。所有姿态和编码器与源 RGB-D ID、checksum、时钟绑定。预测隔离物理标签、密图与已知针几何。
2. 采用已批准的无 SciPy 窄替代。每端点比较含当前的 1/2/4/8 帧。固定共同腕系旋转为窗口中各帧实测候选，以当前冻结的全部旋转矩阵分量原界验证每帧。以共同腕系平移为变量，将各帧各自的原锚点及杠杆臂代入三维半空间。枚举三个线性独立约束面的顶点，以可行内点向内移动后保守复核每一原始约束，丢弃贴边、奇异和数值未知。找不到见证不能认定整个可行集唯一或为空。
3. 同端点机械臂与原相机在原模型中仅刷新运动学。对原密采比较的固定射线，用 native mj_ray 判断每个可行完整刚体的首交面。相反见证须连续满足整个窗口的原界，并有足够的入射、侧缘及竞争面余量。证明两姿态的首面相异后，追加验证同一对是否适用于九帧以上直到真实持物历史起点；求证范围逐项记录。2 帧见证不能替代 8 帧见证。重点为原 06/1736、降速 04/1832 的 36 条射线。
4. 控制包含滑移使假设失败、掉帧、跨案、重复及开爪。两次仅光学冷预测封存后，独立读取物理框架变换，量化已记录轨迹的相邻腕系平移与转角，沿 0/0.1/0.5/1.0 mm 和 0/0.05/0.25/1.0° 诊断格标示实际超限数。实际标签不回填预测；诊断格没有误差证书。旧 t02 针与无针同图及原实际制停反例单列。
5. 找到完整可行的成对见证即说明该窗口的历史资格界加零漂移仍不足以唯一确定该射线的几何首面。结论限制在姿态所用光学证书与几何，不宣称完整观测必然不可区分。无见证保留未知。仅允许两次盲 CPU 预测和一次隔离标签读回。新增相机曝光、渲染、积分、动作、整机、独立正式评分、正式仿真、硬件和远程均为零。
