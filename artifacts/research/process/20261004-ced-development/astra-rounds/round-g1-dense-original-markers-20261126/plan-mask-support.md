# Astra 补轮 · 用遮罩外的 ID8 深度点拟合板面

原两份盲读逐字节一致，均为 SHA256 `d7c33b09c5c1f7aab1c9761c2713120b4ddb9450c0e9de67a6e8dc41e30ea27d`。十二张密图均直读 ID8，十张常规图中七张的标记内部深度多边形触及保守排除区，两个横梁 STOP 因此未评分。初轮执行源码保存在本机，SHA256 `0ca8223716a0e80c7b6bc2fe81d83a8ee40bcff4551de42426ce3cd9d41cc6d7`。本补轮保留失败原件和原遮罩，只改变证据要求为对遮罩外的原标记深度点拟合板面。

1. 保留顺序四角及 ±6 角点和中心邻域均在禁区外。把禁区填 0 与 255，重复冻结原字典的直读解码和角点细化，要求与原中性遮罩相同的已注册唯一有序四角。按固定 6×6 原注册黑白格，取每格预登记的 3×3 亚格点，核对原图双线性四邻域均未触遮罩，独立以 Otsu 逐点二值化，所有点均满足原字典格位和唯一方向。填充值不进入深度。
2. 以原 `_pixels` 取标记内部坐标，先剔除遮罩坐标再取有效轴深，保留原最少 55 点、点到面的内点条件和公共平面算法。保持原单标顺序边与坐标变换，禁止原 `_opposite_edges` 和真值。最终内点在标记平面四个象限内均有样点，二维秩通过、凸包严格包含标记中心。记录各阶段的点数与实取坐标。仅在内存把禁区深度替换成两个固定值，要求实际使用的坐标、平面和姿态逐项相同。
3. 同算法盲读全部十二帧，两个冷进程逐字节一致后才开放物理标签。初轮已可测帧必须重现同一组采样及姿态；若原数据无法满足新增依赖性控制，单列拒绝。按原计划复核两个横梁 STOP 的 36 条既有射线、代表边界、零误差点估计和固定假设方向界，针和无针同规则处理。此证据只支持候选筛选，不赋予新的绝对界或准入。
4. 输入和 SHA256 继承原计划。保持原真值和旧评分的盲读限制。新增盲读最多两次。新增相机、GL、积分、控制、整机、正式仿真、独立正式评分、远程和硬件均为零。
