# G1 B03 两个目标区偏移点的原生 RELEASE 静态复采

原 B03 原位和两个登记偏移各复采三张原生 320×240 顶视 RGB-D。原位三张的 RGB、有效掩码及有效深度位值均复现冻结 B03，保留原独立姿态及当前支撑缺失。两个偏移在三个时点都取得 ID8 加独立对侧印迹的合格姿态、当前支撑和双侧间隙。独立物理核对确认六张候选图的姿态界与两侧净空间隔均覆盖对应静态状态。[Astra 计划](plan.md) · [逐帧证据](fit03-offset-native.public.json)

| B03 条件 | 冻结 RELEASE 联合单帧通过 | 左／右净空下界各自最小 |
| --- | ---: | ---: |
| 原位 | 0/3 | 无签发区间 |
| P，(−10, −30) mm | 3/3 | 1.401／1.572 mm |
| Q，(−20, −30) mm | 3/3 | 1.538／1.466 mm |

每张只直接解码 ID8。两个偏移实际得到 `id8_opposite_ink`，沿用原印迹规则、方向误差和严格双侧 0.25 mm 门槛。九个静态状态中原生封存轨的两侧物理净空最小约 4.637 mm，平移及同腕复位核对保持该物理边界。两个偏移都支持本轨的静态光学复现。三个静态时点仍无法替代未采的 31 帧连续驻留，B01/B02 的共同选点也没有建立。[三轨几何, 共同选点为零](../round-g1-release-region-offset-20261126/step-report.md)

实际请求 9，原生帧 9，封包 49 件。两次冷读逐字节相同，源装配、原相机/同曝光编码器、左右区间覆盖和捕获时钟均已重核。第一次冷读文件写到工作树根，验明其绑定的捕获散列后移回隔离结果目录，随后用第二次冷读逐字节核对。Ruff 和格式检查通过。新物理积分、控制动作、整机、独立正式评分、正式仿真、硬件与远程均为零。
