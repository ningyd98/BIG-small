# Astra 计划 · G1 B03 原顶视偏移点的静态原生复采

模型 gpt-6.2-astra，基线 `92e2faf1991e384bff6f538028632bc6263982da`。原目标区几何 81 格没有九槽共同候选。第三条拟合轨的两处偏移各有三个停留时点达到理想光学前提。新实验只检验该一轨的原生静态观测能否相应恢复独立当前姿态、当前支撑与双侧间隙。

1. 复核两份几何结果逐字节一致，独立读回共同候选为 0、下述两个偏移各 3/3、原 B03 标签及旧正负控。固定三个时点 5420/5540/5660，每条件三次，顺序 q0 原位、主要偏移 P=(−10,−30) mm、相邻偏移 Q=(−20,−30) mm。Q 单独判读，不补 P 的缺口。B01/B02 只引用已有几何结果。三次均来自同一拟合轨。
2. 装配、摄像机、深度噪声、标定、原 OPEN 来源与读者继承冻结原生 RGB-D。候选使用几何筛查封存的七轴值及目标区轴定义的该世界平移。恢复原工件姿态、Z、双指、时钟、速度和控制；无积分地刷新派生几何。保存历史源与候选静态恢复的身份、关节、物体、指垫、TCP 变化各自的回执。复核原桌面接触、目标区实物包含、原指垫间距、腕姿、相机与时钟。实际赋值姿态和重新反解的曝光编码器各按其域精确关联，不互相要求逐位相等。
3. 在原设备和独占 EGL 锁下真采 320×240 的同 seed RGB-D，原 q0 三份逐像素／有效深度逐位等于旧 B03，并复现原拒绝，才采 P、Q 各三张。每次只一次原入口，统一 seed=649300+绝对源步。封存原生 RGB 和深度前后状态、请求、曝光、关停和失败回执。不补拍、不切换候选。
4. 预测只看原生图、静态标定、同曝光编码器和已经验证的命令关联，禁止物理标签及偏移真值进入。冻结预测后两次独立读回验接触/间距/区间包含、姿态界和固定原判据。逐条件报告原可见/可用 ID、合格姿态、支撑与 rim、同帧双侧区间及联合门。物理与真区间不覆盖或假通过中止；如仅获部分证据，完整保留拒绝。
5. 只有 P 的三帧均过静态联合门才称该一轨的主偏移静态复现。P 与 Q 均 3/3 才称两个登记点均复现。最大九张新曝光，新增积分、动作、整机、正式仿真、独立正式评分、实机、远程均为零。三帧不是连续 31 帧在线释放，也不纳入三项研究分母。
