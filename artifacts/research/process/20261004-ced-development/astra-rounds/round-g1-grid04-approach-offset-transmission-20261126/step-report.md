# grid‑04 原生接近偏移的实际传递

历史 12 个摆放的 96 个同抓高原生配对均有 APPROACH 返回，所有 ±2 mm 指令的实测切向位移方向一致，绝对值范围 0.597–2.077 mm。按原配对从同一个 MOVE_ABOVE 返回态及像素来源计算。保留闭爪后相对腕位姿、双侧接触及原轨失败。两份独立冷读逐字节一致。这些原样本使用工件 Y 切向，不能视为 grid‑04 的固定腕 world X 试验。[原始结果绑定](approach-transmission.public.json)

grid‑04 的 A 精确复得第 1280 步终点、原第 153–235 条命令和原 GRASP/PRE 编码器与工件状态。B 从同一完整第 872 步状态开始，目标 world X 减 1 mm。第 877 步第 154 条目标开始分岔，第 878 步驱动和实测 TCP 均开始不同。两支最后共同步 1280，B−A 的 X 已为 **+1.078 mm**；B 于 1288 步返回，按各自返回态比较为 **+1.323 mm**，Y 和 Z 分别差 +0.087、+0.466 mm，腕姿差 0.370°。该候选确实改变了接近路线，但实测位移反向。未派发 GRASP 或 LIFT。

恢复前一次复演在外层与原生伺服采图作用域重入时停止，已耗 872 步。保留逐字节首版源码及首败日志。恢复驱动分别验证原生作用域正常、异常退出，仅屏蔽该 CPU 实例的自动帧刷新。第二次完成 1696 步。共两个 reset、2568 个积分步，EGL、原生采图、正式、独立正式评分、硬件及远程为零。两个最终读回附原终点来源与独立关节 FK，拒绝临时副本中的 GRASP 命令、重复端点和以目标冒充实测 TCP。初次档案读取按字符串而非实际结构理解候选 ID，在物理尝试前已修正。[恢复边界](recovery-plan.md)
