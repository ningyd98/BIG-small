## 像素和页面复核

验证器先从 PDF 图像列表辨认实页，再从 MuPDF 设备跟踪读出图像矩阵、路径裁剪和图像掩膜。给每个源 PNG 单独制作一页同尺寸、同位姿的无裁剪参考 PDF，以相同的 Poppler 在 150 dpi 取样。参考页仅含原图，不引用被测 PDF 的文字或图像对象。实际稿件则另从 PDF 直接渲染整页，并与从 Word 重导、渲染的对应整页 RGB 比对。同一版本的 26 页全部一致，旧版、A、B、C、D 共比对 130 页。

两边灰度图以 1 px 半径平滑，取参考灰度小于 247 的像素计算 Pearson 相关。先对整图在每轴 ±2 px 的整数范围内对位，每幅图各区共用一次位移。终版所有位移均为零。31 个命名区域覆盖云、边、端方框及箭头，三张相机图的完整视野、纹理和标签，两张统计图的各组柱形、刻度、单位和 10 mm 阈线。回执还列出四幅整图，源坐标、页坐标、每区有效像素数、相关系数和对照图摘要均可查。

最初用 Pillow 双三次投影原 PNG，在四张终版图中得到的最低局部相关分别为 0.861480、0.791534、0.698288、0.779999。最明显的差异发生在细虚线和小字。改用同一 Poppler 分别渲染独立参考页与被测页，使两侧的采样核一致。分区、灰度阈值和 0.90 验收线沿用原设置。两套结果均由同一验证器重算，前者保留在每幅图的 `alternative_pillow_bicubic` 字段。旧版四图继续在几何和内容两项检查中被检出。[验证器及区域定义](verify_layout.py)

第一次修复形成 A、B，四图已完整。逐页审阅发现表 6-5 题名留在第 20 页，首个数据行在第 21 页。根任务使表题与其后表格连排，得到 C、D。B 到 D 仅第 20、21 页的 PNG 发生变化。最终七个题名与第一数据行同页，按表 2-1、6-1、6-2、6-3、6-4、6-5、A-1 顺序，实页依次为 8、16、17、18、18、21、25。表 6-5 的首行已读出“移至上方”及“120／835／2,040”。

根任务逐页审阅 B 的全部 26 页联系表，单独检查第 9、20 页原尺寸页面，并审阅 D 的变动页联系表及第 21 页原尺寸页面。独立图像复核检查四个图号对应的旧、新实际页面局部和图注，包括三栏相机视野及标记、流程返回连线、阈值虚线和正式 LIFT 四组数字。上述分工加上 C、D 逐页 RGB 与 PNG 双重比对，覆盖全部终版页面。五版 Word 主体全部可见文字的 SHA256 相同。两次终版的 11 个目录项均与实际标题页相符，从中英文摘要的第 3、4 页起，七章起始页依次为 5、7、9、12、14、16、23，第 24 页为参考文献，编号 1 至 14，第 25 页起为附录。封面保留“研究阶段稿”。

## 复算与原件

Astra 两份计划 SHA256 分别为 `d5995b3e3bcc0ea68b3458109a529de252cb0631666bd16a8308c4347248cc23` 和 `9ca573fae38480a32f8eac592b0f70fa9903f4ddeb51e19ced85d2a9cccb4b1c`。基线 16 项均复核，已变更的构建脚本另在内存回退本轮两处分支改动后校得其原 SHA256。私有旧稿的 DOCX 和 PDF 与原发版摘要一致，基线旧页和联系表均已保留。重新排版使用既有构建入口，独立验证使用 Python 3.12.14、Pillow 13.0.0、NumPy 2.3.5、ReportLab 4.4.9、MuPDF 1.23.10 和 Poppler 26.05.0。项目 Ruff 0.14.14 对验证器的检查和格式检查均通过。

在工作树根目录下，将 `E` 指向保存这些构建和页面的私有取证目录，`PYTHON` 指向装有上述 Python 依赖的解释器，即可另行输出核验报告。以下 Bash 命令保留五版完整分母。

```bash
R=artifacts/research/process/20261004-ced-development/astra-rounds/round-graduation-manuscript-figure-layout-20261123
name=云边协同机械臂毕业设计
editions=(--edition old "$E/pre-figure-layout/$name.docx" "$E/pre-figure-layout/$name.pdf" "$E/word-pages-release")
for version in a b c d; do
    dir="$E/figure-layout-$version"
    editions+=(--edition "$version" "$dir/$name.docx" "$dir/$name.pdf" "$E/figure-pages-$version")
done
mkdir -p "$E/figure-recheck"
"$PYTHON" "$R/verify_layout.py" "${editions[@]}" --baseline old --final c --final d \
    --manuscript docs/thesis/graduation-20261123/manuscript.md \
    --evidence-dir "$E/figure-recheck" --output "$E/figure-recheck/verification.json"
```
