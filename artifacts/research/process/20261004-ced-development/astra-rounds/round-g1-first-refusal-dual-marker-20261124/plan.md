## 已知失败与本轮问题

四对新摆放 m01–m04 的八次真实 MOVE_ABOVE 全部派发，四次 +Y 和四次 +X 均在真实反馈中丢失 ID7，控制器返回 servo registered marker geometry unavailable。前一个 30 Hz 反馈尚有效，其时刻恰早 8 个 240 Hz 物理步；中间七步没有伺服相机采样。另拍的 terminal 是同一步不同帧。独立成功两组都是 0/4。此前另一批停机姿态或教师轨迹的结果只作背景。本轮检验遮挡墨格、静区或邻近轮廓、采样与角点解码、深度及登记构形等解释，容许证据无法区分原因。

## 原始证据与双向复核

1. 检查 Git、源/测试/资产/原件清单、八例 allocation、receipt、SQLite、audit、逐步状态、pixel-index、decisions 及真实 RGB-D 哈希。以现有 run/servo visual_samples 对齐按顺序的 MOVE_ABOVE/feedback，确定最后接受与其后唯一首拒，分别对齐 8 个控制周期边界和独立 terminal。禁止以 pre、重复末帧或相邻 episode 代替。记录 source episode、原臂、frame_id、checksum、文件 SHA、物理步、时钟、实际控制接受目标/拒因及五点深度。每例保留首拒前后共9个逐步状态的步号或边界及中间七步无像素说明。
2. 每个案例的前一有效反馈和首拒各一源姿态，共16个。对每姿态各恢复同一关节、两指、物体位姿/速度、时钟；使用原 r593 +Y100 和 r579 +X100 的单 ID7 资产，保持同一 nominal 320×240 顶相机、光照、遮挡手臂和噪声标准差 0.001 m，配对种子为 24113000+2×源槽零基序号+时间角色序号(前=0，拒=1)。仅 mj_forward 静止成像。借用 g1_mount_screen.restore_and_capture、proposal_camera.restore/compare，逐帧确认 RGB/深度/实例来自相同状态，来源臂复现与原 RGB-D 通过 CHECK_LIMITS 原六项（TCP≤10µm、物心/朝向分别≤1e-8、RGB变像素≤0.0025、深度有效掩码差≤0.005、共同正深度差P99≤0.006m），复核原判结果。正常图32张，16个配对，分前/拒各8、各原臂各4；附原实际16帧与独立 terminal 8帧。缺失单列并保留分母，修复重建证据后再解释。
3. 封存匿名帧和身份映射。盲进程仅凭原分辨率 RGB-D 和登记几何跑 OpenCV DICT_4X4_50 SUBPIX、0 纠错、原 rejected-candidate 精确解码；记录直接识别/拒候选、ID、四个有序角和边长、五处3×3深度正值/平面及姿态、物顶/抓取点。单标有效沿用 g1_mount_screen_pixels.estimate 的 usable 判据。解盲后用 g1_mount_screen_score.projected_regions、实例标签、光学深度和真实刚性变换，分别计数黑格、白格、白静区的投影总像素、正确实例、手/两指、其他连杆/物体、深度近5/20 mm，记录逐手距离、边界/可见率与范围外像素。不要将实物缺失、静区被遮、邻近手轮廓或深度失真混作同因。
4. 全部32张正常图对应32张仅隐藏 hand/left_finger_geom/right_finger_geom 的同姿诊断图，遮挡开关可逆，几何/噪声种子与相机不变。正常和隐藏图均记录四个投影角的像素小数相位、像素/格、相邻边缘像素、候选四边形/恢复解码，支持原判到具体失效环节。另在正常图上做纯离线 x/y 各正负0.25像素的四个单轴灰度双线性平移解码压力测试（32×4=128，边缘复制，观察ID/候选变化，不从移位图估计物理坐标）；该测试同时改变插值，阳性写“对亚像素采样/插值敏感”。相同种子隐藏后恢复且相应区域有更近手像素支持该区域的贡献；仅隐藏恢复而纸面无手像素时检查静区外近邻和候选轮廓，写“手部外观影响”；诊断无足够区分力写未决。诊断和真实反馈、正常重建各自计数。
5. 分别列出前与拒的 both / X-only / Y-only / neither 四格、八例逐对所有读数、源侧丢失时另一侧是否救回、各侧联合覆盖。触发规则在16个原姿态中至少各有一个已核实的正常 X-only 和 Y-only（即正常并集严格高于每个单侧，允许发生在不同时间角色）。阳性即开展下列双标开发，不要求八例全部救回或给出显著性；未发现双向互补时按同一规则报告结果。未验证的格不能充当独救见证；若余格未知且可影响结论，报告未决并优先完成取证。把决定和两个见证的 SHA 封存后才能启动新的运动。

## 独立双标场景与在线链路（条件触发）

从研发基线导出隔离运行树，提交仅限开发脚本、新资产/登记描述、专项测试与公开报告，不改原 r579/r593 文件和正式部署。+Y 100 mm 继续用 ID7，+X 100 mm 采用不同码 ID8，两者 DICT_4X4_50，75 mm 印刷宽、100 mm 白底，印刷顶面相对方块 [0,.1,.03505]、[.1,0,.03505] m。逐码逐格比对 OpenCV 字典；两印刷面水平共面，各自白底无正面积重叠。70 mm 方块、原顶视标定、相机和目标区沿用原配置。给两块板登记同一刚体上的实际承载薄板和连接到方块的窄支撑（接触壳、正厚度和质量），避免白底浮空、板相互穿透、与台面/初始机械臂重叠或纹理 z-fighting；同一刚体内连接处允许贴合。视觉墨格可零质量/无自碰撞，支撑与载板的质量和惯量、可能碰撞须披露；对双标组任何物体-手接触按 geom 分清夹方块/碰支架，不能凭接触支架授予夹持成功。优先采用直接 object-local named boxes，验证编译、接触位/掩码、板几何、码轴、两处 FK、净距、质量/惯量、相机/控制器/物体 TCP。运行前密封有效 XML、几何、来源及源码清单。

旧 detect_pose_marker 明确在 len(observed)!=1 时拒绝；旧 NativeGeometryRegistration/marker_family 校验所选家族，registered opaque primitives 固定38盒。完整保留旧接口的历史拒收，使用独立开发注册表、严格校验器和运行树中的受限适配，不宣称取得正式登记。绑定真实资产 SHA、每个 ID 的有序角/字典/刚性变换、场景/相机和开发源码代际。每张原始全帧只从当前 RGB 像素找候选四边形，按真实 ID 区分，不从仿真位置、存档、框选真值或回填历史姿态。按原准则保留精确解码与去重的物理候选，重复相同 ID/外来 ID/模糊身份拒绝。逐 ID 沿原 SUBPIX 角点、五点深度/平面、尺寸和 upright 门槛恢复世界位姿，按 world_T_marker × inverse(object_T_marker) × object_T_tcp 求同一个抓取点。仅一侧合法则使用该侧；两侧均合法，若两抓取点相距≤10 mm 则固定使用 ID7，超出则拒绝。无合法侧则拒绝；对出现但几何不合格的一侧单记原因，另一合法侧可用。优先按 decoded ID 选角而不改变图像、观测 ID/校验和/时钟。沿用默认 OpenCV 无纠错和原精确候选法，避免同一角点被直接解码和 rejected 回读两次。

## 新摆放、结局和交付

四个新摆放 d01–d04，原 +Y 和双标各四次，依 plan.json 固定 AB/BA 次序、坐标、偏航及种子，同一组每臂独立重置/独立 worker db，各槽一次。实际开始时用排他目录锁定槽；运行中断保留所有原件，不补跑。按序提交 MOVE_ABOVE、APPROACH、GRASP、LIFT、MOVE_TO_REGION、PLACE、RELEASE、RETREAT 全意图，真实停止即据实纳入。冻结实现/登记和分配后运行整批，不能按得分调整方案、姿态或重复失败槽。

新进程重算每帧几何与实际在线 targets，逐例验证原状态和 action/receipt/命令/SHA/时钟；物理评分复用 proposal_scoring、g1_mount_score 和原 LIFT 121 / RELEASE 241 个连续样本、原安全及目标区阈值，从原 dense 状态和实际行动边界独立核对举起、持稳、落在目标区稳定、释放和受检违规。报告双标与原 +Y 各自独立物理成功/分配4、在线完成/4及两者同时/4，列分子分母、Wilson95%、配对差与区间。中断/缺失给出未知和界限；动作未入场时相应帧率/P90无分母。按动作、组别、ID以及仅一侧/双侧给出可用帧/全部采集、有效帧物顶三维误差P90、首拒/保护原因、物理窗口及支撑接触。开发目标背景是P90≤10mm与独立静态成功率≥90%，任何结果均可交付；不因小样本作正式验收。
