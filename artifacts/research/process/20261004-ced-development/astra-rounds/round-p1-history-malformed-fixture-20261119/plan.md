# 历史位姿索引识别已知的故意损坏夹具

## 证据

- 首次 freeze 在读历史 JSON 时退出 1，未创建预登记或 BEGIN。首份全向量 1724 个候选仅一个字节为 { 的 protocol.json 无法解析。suite-02 的 nodes 含 test_malformed_protocol_claims_are_invalid[{]，历史测试明确写入 { 并要求 INVALID；对应旧 pytest basetemp 中的这一个文件正是此负控。

## 执行

- 只修 development_plan.py 的研究历史读回及相关定向测试。以既有具名历史根、精确相对路径、文件类型、长度与 SHA、旧 suite 启动/节点/结果及历史负控源码绑定此唯一故意无效样本。照常把它列入历史原件向量并标为已核对的 pytest 负控，贡献零 seed 与零位姿；不可把它冒充合法生产历史或忽略整个 tmp。其余 JSON/JSONL 照常严格解析；换目录、换摘要、未知坏行或缺失已绑定原件均须明确拒绝。

## 前置

- 保存首次日志、旧工具源码和完整路径哈希向量。优先让原历史向量完整校验；受控坏文件只读。验证时不启动模型、不创建 claim 或 B0 assignment。

## 验收

- 负控应拒绝第二处坏 JSON、同字节不同来源、同源改字节；有效历史仍贡献 seed 和位姿并能拒绝重叠。重新运行完整索引，在成对冻结的输入上重建结果；报告读入数及唯一已知夹具（1724 为首次输入数，新增实际来源须列明）。20 个独立 seed 与位姿按实际历史/教师/B0/后续池无交集，两次复测作为预声明例外单列。其余前置具备便继续已授权的注册/真实执行，初次失败未消费任何槽。
