# grid-04 原位 −1 mm 指令在两个首拒位置的读回

两个冷读进程从第 1280 步真实 GRASP/PRE 原图复得当前闭爪机会通过。角度上界为 2.300894°，组合域半径平方 0.491469，旧中心高度门为假。原指令 TCP 和实测 TCP 的 Z 差约 3.0 mm。冻结网格中选定的固定腕 −1 mm 项，在保留原到位偏差的条件构型下组合域半径平方为 0.510501，当前闭爪机会仍通过。[条件构型及输入](tangent-readback.public.json)

分别从原 2112 步和尾段 2384 步的封存实测关节状态调用冻结原生 IK。对每处的当前 TCP 与同高水平 −1 mm TCP 目标，均保持原 `_DOWNWARD`，两种目标都逐元素返回原七轴位置，最大关节变化 0 rad。固定工件及机器人状态的条件下，整个临界像素锥和 3×3 邻域的几何遮挡输入因此一致。这个结果排除了在这两个已失败位置直接用该偏移产生新的光学视角，较早改变 APPROACH 和闭爪后的相对姿态仍未验证。

每项两次 CPU 冷读，规范输出分别逐字节相同。原生集成、采图、动作、正式、独立正式及硬件新增均为零。保留首拒及 LIFT 原合同，未签发非零目标。[计划](plan.md) · [计算源码](read_lift_ik.py)
