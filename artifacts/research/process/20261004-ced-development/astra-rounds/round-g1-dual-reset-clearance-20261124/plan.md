# 双标记结构与桌面净距预检修复

gpt-6.2-astra 于 2026-11-24 制定。父计划、互补判决、冻结模型、资格门限及八个预登记运动槽继续适用。私有运行树的首次 audit_asset 在首个真实探针拍照前以 g1_dual_id7_support/table 净距为零而拒绝，0帧、0步、0派发、0正式分配。两处固定姿态44对/姿态的独立只读核对显示，原 MuJoCo 3.3.7 mj_geomDistance 在 distmax=3 m 下对 ID7支架/桌面一次、ID8支架/桌面两次返回0；这三对的世界包围盒均严格相隔68.01 mm，全88对分离下界均至少68.01 mm。现有接触表仅列台面与方块。原始 API、资产和读回指纹见 plan.json。待检验原因是该查询在这些薄盒体组合给出与几何互斥的零值；不能由此推断其他碰撞查询都失效。

1. 在独占、尚无运动分配的状态下，先逐文件校验首代锁、开发资产、公开锁的原始字节、首次错误和空 probes。将首代运行树和空 probes 原样无覆盖地移入 D 下独立保留目录（例 reset-clearance-first-generation/runtime-source 与 probes；同文件系统 rename 即可），保留失败日志及其哈希、原 D/vision 记录。补充轮固化首代公开清单原字节为 runtime-build.first-failed.public.json，保存失败日志/只读观察摘要及阶段清单，写明首代锁→存放位置。仅在已保存的公开锁与首代私锁完全一致后更换父轮当前公开锁。保留原失败日志；第二代另写日志，不以 > 覆盖。首代所有文件、锁、无输出探针和首次失败分别可查证。

2. 在独立开发 g1_dual_asset.audit_asset 的静态净距子项上实现保守实数判据。对所有4件承载结构与台面及10个机械臂几何按完整名称、姿态和世界坐标取编译后 geom_type/size、data.geom_xpos/xmat、同一 mj_forward 与接触对。BOX 世界轴投影半径为 abs(R)@halfsize；CAPSULE 用 r 加 half_length×abs(R[:,2])；CYLINDER 用 half_length×abs(R[:,2]) 加 r×sqrt(max(0,1-axis_z_components²))。核验类型、有限值、正尺寸和正交旋转。以 max(a_min-b_max,b_min-a_max,0) 分轴求欧式范数，计算在圆整容差内向外扩张包围盒（例如各面1e-12 m）后的保守下界。原始未经扩张下界也保存，对平行桌面的薄盒用其真实最低点和台面上表面核对，垂直投影重叠时给出精确实际间隙。其余已证实分离对将下界标明为下界，不把它当精确表面距离。每对留未经改写的 distmax=3 m 原 API 读数、必要时双向/不同截断值与 witness、几何和包围盒、分轴间隙、裁决理由和单位，分别汇总88对和三个矛盾项。

3. 区分接触记录、解析证据和查询歧义。在结构-台/臂接触时拒绝；仅严格正的经保守圆整的下界即可证明该对分离。下界为零时允许通过经独立验证的形状特定精确几何严格证实正距，也可保守拒绝；不单凭一个正的 raw API、无接触或非负截断值放行。非有限/未知形状或证据不一致而无法证明时拒绝。有限原始零值与严格分离的有效解析证明并存时如实记录。几何预检仍要求全部88对严格正净距、装配/角色和其他原门限全部通过。场景 XML、质量惯量、物理接触、原相机、视觉/控制和 SafetyShield 字节保持既有设计。禁止改变工作场景以提高净距、扩大距离阈值或跳过支架/台面。

4. 预计 RED 包括首代真实失败及负控；先做单元和局部实体检验，覆盖旋转 BOX、倾斜 CAPSULE/CYLINDER、有间隙且 API 为零、边界正好接触、轻微穿透、包围盒重叠且无严格分离证据、非法类型/非有限。至少用隔离的真实 MuJoCo 测试模型构造一处精确贴合、一处穿透（比如支架与台面），以独立已知几何位置和全精度变换证明拒绝，零动态积分、无运动。回读首代两姿态的88对并与新审计逐项比对，复核下界和真实 table clearance。独立读回可扩展 g1_dual_probe_readback/专项测试与清单序列化，以复算上述几何和匹配实际生效锁。资格与分配的证据可分两阶段写：探针/编译几何完成先核查，八槽发放后补核 slot/asset/资格 SHA 和最终读回。保持注册、动作和安全条件。

5. 用修复的开发代码按原 builder 在新 D/runtime-source 重建开发运行树，生成第二代私锁与父轮标准文件名公开锁，声明两代哈希、差异路径和继承的不变输入。在新 D/probes 通过原真实零步入口获取正负控，保存每帧、检查结果和新日志；严禁将首代空探针或失败预检计入正控。按原先互补门和未变的资格门判定；资格完成后仅由父计划发放其8槽、各一次，严格绑定第二代清单与零步 seal。独立重算资格、分配、真实数据；首代和补充轮非原批次分母。出现其他根因先留原始输出，再由 Astra 制订新计划。补充报告区分软件、实际静态净距和实际零步资格，正式新增0。
