# 双标记预检的静态净距复核

两处预登记重置姿态共检查 88 对实体，均取得严格为正的分离下界。四个承载件在两种姿态下与桌面的实际垂直净距均为 68.01 mm。其余 80 对由完整世界包围盒证明分离，各轴向外扩张 1 pm 后，全组最小保守下界为 68.009999998 mm。两处均采用编译模型的正向运动学，动力学积分和动作派发各 0 次。

## 首次拒绝与来源

首代预检在 ID7 支架与台面的距离查询返回 0 时停止。该代采集 0 帧，产生 0 个运动分配。MuJoCo 3.3.7 的相同查询在第一姿态对两只支架各返回一次 0，在第二姿态对 ID8 支架返回一次 0。三组实体的世界坐标均给出 68.01 mm 的正间隔。第一代和第二代的 88 个原始查询值、未经扩张的下界逐项一致。补充计划的 14 项原始输入已按首代归档重新核对。

## 净距计算与负控

对 BOX 用三条局部半轴的世界投影求边界，对 CAPSULE 和 CYLINDER 分别使用轴向长度与球端或圆截面的投影。检查类型、尺寸、旋转和有限值后，每个面向外扩张 1 pm，再向外舍入一个浮点数。分轴间隙的欧式范数给出表面距离的保守下界。对八对水平板件与台面，板件最低面中心的垂直投影落在实际台面内部，因此该垂线段给出了精确间隙。每对保存两组几何、世界包围盒、分轴间隔、原始引擎返回值和接触状态，三个零值另有双向查询和端点读数。

七项专项软件用例均通过。真实编译的小型模型上，0 mm 贴合时接触表为空，程序仍拒绝。0.05 mm 穿透时模型报告四个接触点，程序拒绝。保留 68.01 mm 间隙时引擎返回 0，保守几何和桌面精确间隙均证明分离。另一组斜置细盒具有正的引擎返回值，世界包围盒相交，程序因缺少严格的分离证明拒绝。原单标五组回归共 291 项通过。

证据见 [逐对读回与测试指纹](clearance-validation.public.json)、[首次失败清单](first-generation.public.json) 和 [补充计划](plan.json)。本步骤覆盖实体的两处初始构形。双标零步视觉资格和实际运动结果使用父轮的独立记录。正式仿真、正式 claim、硬件动作与任务模型调用均为 0。
