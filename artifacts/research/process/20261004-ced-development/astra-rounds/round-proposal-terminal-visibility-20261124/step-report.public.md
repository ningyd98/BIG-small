# 双机位重观测的终态与在线试验

在八次已封存的失标停机姿态中，名义机位停机的四个姿态均能从平移机位重新取得 ID7 和原伺服所需的有效抓取几何。平移机位停机的另外四个姿态，从两个正常机位都无法取得有效几何。每个对照都来自同一 episode、同一物理步和相同的关节、手指及物体姿态。[八个终态的分配](observation-allocation.public.json)

| 同一姿态下两个正常视图的结果 | 终态数 |
| --- | ---: |
| 两者都可用 | 0 |
| 仅名义机位可用 | 0 |
| 仅平移机位可用 | 4 |
| 两者都不可用 | 4 |
| 重建未通过 | 0 |

独立盲读覆盖 32 份再渲染 RGB-D，以及八条原轨迹各自的前一张成功反馈、首张拒绝反馈和同一步的终帧。16 份正常视图分割用在判读封存之后。在模拟渲染中单独隐藏手掌和两指时，16 个视图全都恢复注册几何。这项干预说明手部影响了上述姿态的可见性。两个机位能否在真实动作中补足证据，另以新轨迹实测。[同态对照及分割](observations.public.json)

## 新摆放的成对运行

名义机位和平移机位均从真实中性重置取得新的 tracker 登记。各方向独立试采两张新帧并回到起始机位，耗时分别为 38.87 ms 与 37.99 ms。两组新摆放各跑固定机位和有界重观测一次。干预只在 MOVE_ABOVE 和 APPROACH 的单次运动反馈中允许一次额外采图，使用同一物理步、另一机位的真实标定、原始伺服与 SafetyShield，随后回到该组的初始机位。后续动作仍读取本组登记机位的证据。[试次及预检](switch-allocation.public.json)

| 摆放与方法 | 已通过动作 POST | 首个停止位置 | 成对观察 |
| --- | ---: | --- | --- |
| v01，名义固定 | 0 | 第 832 步，MOVE_ABOVE 失标 | 当前机位的反馈无法继续 |
| v01，名义起始可重观测 | 1 | 第 832 步，APPROACH 派发前的注册几何检查 | 同一步的平移新帧获伺服及 Shield 接受，MOVE_ABOVE 完成。复位到名义机位后下一动作仍缺标记 |
| v02，平移起始可重观测 | 1 | 第 1,032 步，APPROACH 失标 | 切换后的名义新帧同样无法定位标记 |
| v02，平移固定 | 1 | 第 1,032 步，APPROACH 失标 | 当前机位的反馈无法继续 |

v01 的换视角样本耗时 55.08 ms，控制器独立记录的含逆解耗时为 60.48 ms，低于原 100 ms 限制。v02 的失败样本耗时 50.28 ms，因视觉证据不足而停止。两个方法均为 0/2 完整成功，抬升与释放的独立保持窗均未到达。每个方向只有一个摆放，一次成功重观测仅证明在该运动反馈时刻取得了可接受的证据。[逐例动作与停止](switch-results.public.json)

四例共有 3,728 个物理步、3,732 个稠密状态和 439 个实际 RGB-D 帧。429 帧有 ID7 和有效定位，独立物理评价在实际观察范围内四例都未发现安全违规。第二次从原件复算终态表及闭环报告，分别与首次输出逐字节一致。17 项相关回归通过。机位切换属于可取得两个模拟视角的实验条件；单台固定真机相机的可用性需另做实测。本轮正式 claim、模型调用和实机操作均为零。[读回及命令序号](verification.public.json)
