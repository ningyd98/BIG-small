# RELEASE 固定 TCP 的连续关节解分支几何筛查

Astra 规划模型 gpt-6.2-astra。研发起点 `c2edd5e01a20837b680ebda817a6e415caf9c427`。原 70 点静态筛查仅沿局部关节轴取 ±6°，从九个 B 姿态看到的 ID7 最多分别为 458、468、454 点，遮挡侧仍为 0 合格列。原生静态图的部分印刷横轴仅覆盖 16/18、偏航覆盖 12/18，无法签发原 RELEASE。待验问题是保持整个原工具位姿、双指和工件，仅沿同一 IK 分支延拓，能否获得足以登记下一轮原生观测的视线。

读回九个原 B 已开爪状态，分三对轨迹的 +240、+360、+480 步。核对旧几何登记、冻结资产树、旧结果散列、旧 A/B 输入和轨迹对应关系。旧 +0、±6° 计算作为原坐标对照。t02 单列，整条 LIFT 不进入本轮。

1. 只用 MuJoCo 3.3.7 静态运动学。7 轴雅可比使用位置除以 0.1 m 与旋转组成的六维尺度。最小/最大奇异值须严格 >1e-8。初始切向规定 joint4 为正，其后按与上一切向同向取符号。每次采用 0.5° 名义欧氏关节弧长预测，Newton 用原 TCP 六维目标加前一切向的法平面约束来回投。每个回投最多 12 次，校正范数不超过该名义段一半，位置≤1e-7 m、旋转≤1e-6 rad、法平面残差≤1e-8 rad，相邻切向夹角≤15°。每段在三分点及端点回投，任意相邻检查点的实际关节弦长≤0.25°。共享弧长坐标是切向预测长度的名义累加，另外记录实际弦长之和。
2. 检查原 XML 和原生接口目标范围、每轴相对出发点≤45°，冻结非臂关节、物体/相机/时钟及原接触的集合、重数和最深距离。旧禁碰对每项距离均有限且严格大于 1 mm。求解不合格、触界、秩失、接触变化、间距不足、回投走错方向均恢复最后合格态，按 0.5°、0.25°、0.125°、0.0625° 逐级缩小。最小步仍拒绝就停该向。每向上限 60° 或 1024 个接受段，保存最早失败原件。禁止跳过障碍找另一根解。
3. 在名义弧长正负每 2° 计算原 ID7/ID8 视线、码格、兼容字典、两侧有效深度列、阻挡物与最小静距。单槽达到候选的条件为 ID8 完整、ID7 码字只兼容原方向、原双侧各至少 5 列且列跨度至少 4 px。全九槽必须使用同一符号和同一检查点。分别记录独立通过的条件、单槽最高结果和公共命中。公共选择按最短距离、最大最差静距、正向优先。屏幕只提供离散静态几何，实际可见性还需原生彩深与原光学读回。
4. 旧零位及 ±6°、原可见 ID8、错码、错 TCP、缺秩、重叠与拒绝回滚作为对照。验同解分支的小步反向复位误差≤1e-5 rad。两次独立进程冷读同一登记并比较字节。保存所有接触、失败和逐位候选。禁止积分、控制命令、EGL 渲染和曝光。正式仿真、留出、整机、硬件、远程及独立正式评分均为零。即使有公共几何命中也不能签发运动或缩短制停；几何离散间距未证明连续运动或带载动力学可达。
