# 固定 TCP 分支的顶视几何结果

九个 B 放置状态都沿各自原关节解的相同分支到达正、负 60° 名义弧长上限。共接受 2,160 段，并在 6,480 个离散运动学检查点核对原放置支撑、禁碰间距、双指、物体与相机。无试探段被拒绝。全程最小静态间距 4.598 mm，最大 TCP 平移和旋转残差分别为 99.905 nm 和 8.197×10⁻⁷ rad。原零位和两侧 ±6° 的 27 个旧结果逐字段复现。[登记](plan.md) · [逐槽结果](branch-visibility.public.json)

正向 48° 至 60° 的七个共用网格点，九个姿态的理想可见码格都只兼容 ID7 原朝向。首个公共点的 joint4 实际偏移约 +16.93° 至 +17.20°。在 +60°，三条轨迹的 ID7 最多可见 706、722、698 个面点，分别有 318、302、326 个仍被 link2/link3 遮挡。ID8 保持满可见。各轨 +60° 时可见 3 个角格中心，仍缺一角。这些点提供了后续验证注册身份的几何依据。

原双侧方法在整个分支的 549 个登记状态仍无一次获得遮挡侧有效列。三条轨迹保留原另一侧 14、15、14 个理想列的基线，双侧与唯一身份的联合候选为零。原发布的光学拒绝继续生效。t02 抬升在本轮范围之外。检查点的静态间距没有建立连续运动、动力学可达或制停资格。

两次冷进程原输出 SHA256 均为 `2f52e9aae579b27ae28103478483354e3e7e863eb7b8c78325493c70e422d504`。原可见码、错码、错 TCP、重叠、缺秩及回滚对照通过。正向一个名义步再反向复位的关节误差为 2.85×10⁻¹⁰ rad。19 项光学、身份、载物与净空定向回归通过，两个新增研究脚本的 Ruff 检查通过。原数据、登记和两份冷读封存在 `experiments/results/g1-fixed-tcp-branch-visibility-20261126/branch-01/`。

本轮只使用运动学和理想视线。新增曝光、积分步、控制动作、整机、盲评、正式仿真、硬件及远程模型调用均为零。
