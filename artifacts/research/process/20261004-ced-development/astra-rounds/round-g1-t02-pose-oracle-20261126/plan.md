# t02 第 1512 步的独立位姿反事实

Astra 规划模型 `gpt-6.2-astra`，基线 `4929c1a4150e1f52afa462dfd21968d293276701`。t02 的第 1512 步失去独立三维工件姿态，此侧原检测只有 4 色深列、3 px 跨度。原完整门在 1512 记录未归属近面 0、持物关系未知。第 1520 步原姿态恢复但当前因果连续历史已断。第 2112 步另有一个未归属近面，单列且保持原拒绝。

1. 复核计划 SHA、源像素、命令、同曝光编码器、reset 和时钟、原标定、物理标签与旧完整门记录。以角色顺序重走 1264 GRASP/PRE、1504 GRASP/POST、同帧 LIFT/PRE、不同帧 1504 LIFT/feedback、1512 LIFT/feedback。CPU 原关系判据另延伸到封存 1520，通过同一真实前缀比较历史清空的后果。1520 是在原轨迹中记录的图像，新的反事实仅使用它做因果敏感度。禁止用后验帧建立 1512 的前态。
2. 对照保留原姿态入口。两独立反事实分别只在 1512 的同一次原生曝光替换姿态函数结果。中心、方向和标记杠杆锚点根据独立物理标签重建。第一组误差为零，第二组位置、方向同一真值但误差采用原 `id8_opposite_edges` 冻结界以检验该界对原门的影响。保留原检测器、真实命令、当前图和历史更新。记录两指有向间距、SAT 间距、姿态不确定度、有效历史年龄和差、指宽、角/平移误差以及判据原始结果。错帧或校验和、错实例、无历史、历史倒序、已开爪均不得输出 held。两次独立 CPU 冷读输出字节一致。
3. 若任一反事实的原观察器会签 held，可在同一输入与一次 EGL 独占中运行三个完整净空门分支，每段原前缀最多四次原机器人参考深度投影，上限 12。原输入没有保存各次参考深度网格。登记的原 GPU 和 GL、标定、原完整净空门和历史更新保持。只替换 1512 调用中的姿态函数返回，禁止直接代入 held、允许接触或深度归属，不放行控制命令。若触发其他渲染器、摘要变化、复现失败、超限或新输入即停；保留已运行内容。完整门不产出在线许可。
4. 所有路径的原生 RGB-D 新曝光、积分、控制、整机、正式仿真、独立正式评分、硬件、远程调用均为零。即使真实位姿足以通过，也只定位原拒绝链条，须由独立当前光学测量和实际反馈后来建立准入。姿态反事实不用于第 2112 步或 RELEASE。
