# G1 B03 预登记 Q 的实际放置、连续释放与撤离交接前置

规划模型 gpt-6.2-astra。基线 8d58d6071df34a3d7bdaf212632e7db8cd3c0162。

原位 B 实际驻留 0/31，偏移 P 实际驻留 31/31 且物理 241/241。P 末帧原撤离制停下界 −5.056 µm。Q 是静态复拍已通过 3/3 的预登记偏移 (−20,−30) mm。本轮检验实际放置和开爪后能否同时保留连续驻留和正的撤离必要净空。P 到 Q 的唯一输入变化是低高放置目标的 X 再向负侧 10 mm。控制器响应、接触、卸载和可见性属于合计效应。三者仍是同一 B03 拟合，不是独立摆放分母。

1. 复核 plan.json 源件、历史 B/P 封包及逐件 SHA、当前代码、校准和原硬件渲染环境。冻结新程序、预算和同一独占 EGL。只允许新 Q 一条原生路线和一次后续无渲染 Q 命令复演。每条积分上限 7160，总上限 14320。至多 42 次相机请求，包括 10 次原入口隐式、真实 PRE 一次及 31 张连续驻留。B/P 新曝光为零。无其他候选或重复试验。
2. 按原物理和传感种子、装配、帧率和原控制器跑隔离影子路线。逐项核第 2840 步共同前缀与原 B/P 相同。真实 MOVE_TO_REGION 与 PLACE 使用 Q=(0.180,0.220) m，高低 Z=(0.160,0.0492) m、原速度 0.15、加速度 0.5、8000 ms。只在实际原生成功放置、仍闭爪持有、工件在原区且台面正力支撑、无禁碰后，在同一原步采 PRE、保留真实最后目标、实际 hold、由 RELEASE 唯一签发 OPEN。隔离研究的前置与正式在线许可分别记录。
3. RELEASE 真返回在 OPEN+240；复采真实 DWELL0，再每 8 步一次，末帧 OPEN+480。沿用 P 的 PRE 种子 654480 和相对驻留种子 654720+8*i。连续 31 帧原姿态、当前支撑和双侧下界、冻结稳定条件与 241 个连续物理状态同时核对。仍使用双侧 >0.25 mm、指程 >35 mm、原区内、台面独占正力支撑及原速度和接触条件。普通光学拒绝保留窗口；物理、动作、身份、基线、预算或时钟失败即停。
4. 用新命令记录无渲染单步复演到实际末步，逐位校验 32 张显式曝光的 RK4 九轴、同步时间及两次 pass 的冻结状态。先封住物理真值，只用真图和曝光编码器、白名单实际机器人字段、标定及精简 RESET 身份，两次独立冷读冻结光学和原连续 observer。精简请求只含 scenario_id，END 结果只含 physics_dt_s。原地接、实际真值和旧组结果不进入盲读。封存预测后由独立物理读回核对原区间和姿态界的覆盖及连续物理，双冷读也须逐字节一致。缺漏、跨组、等号、假时钟、假 pass、错开爪、漏帧及 RESET 嵌套新增字段作为负控。
5. 只对 Q 的真实 PRE 和预登记最后一个 DWELL 做原 handoff_motion 必要前置。目标速度取真命令前缀、ctrl 保持真生效驱动，PRE 位于真实 PLACE 末目标之后且 hold/OPEN 之前。末帧保留 DWELL 角色。分别报告原域、原模型及延迟、带符号净空、体积和限制物体、原台面许可的严格/条件性结果。完整连续合格、末帧净空严格为正并具有原域与体积证据时，可报告 Q 覆盖的两项本轨必要条件。一律不为在线 RELEASE/PRE 或撤离签发资格，不改变原门及 LIFT 拒绝。

新增任务整机、正式、独立正式评分、保留组、硬件及远程均为零。无实际撤离。
