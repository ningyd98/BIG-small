# 原生技能交接的净空接口记录

冻结的 `LocalClearance.check` 在所有原有身份、当前深度、编码器和实体净空条件成立后，向连续交接门传递原彩深帧、同一帧测出的目标、当前七轴和双指位置与速度、上阶段实际返回步和生效命令、原注册几何。入场 PRE 和同一物理步的首个 FEEDBACK 会重新读取三维视觉姿态和有方向的误差。交接门可借用两个已标定视角核验全部实体的扩展包围盒。共享注册台面上的具名工件接触由原阶段条件控制。
