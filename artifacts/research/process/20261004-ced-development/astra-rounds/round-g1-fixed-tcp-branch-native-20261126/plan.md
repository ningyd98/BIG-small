# G1 固定 TCP 连续关节解的原生 RGB-D 观察

Astra 模型 `gpt-6.2-astra`，研发基线 `dd522fad4b6803db8050cd558e115c639aeda558`。旧 B 九个原生静态状态只识别 ID8，合格姿态、当前支撑、双区间各 0/9。固定 TCP 的 549 点几何筛查中，遮挡侧均无合格理想深度列。正向 +48° 与 +60° 名义弧长使九个状态的理想 ID7 码字各自唯一，仍缺一个角单元。待验假设是同一原生读回会得到可用 ID7 或新的合格姿态，也可能仍受原遮挡和认证约束。两种结果都保留。

1. 复核 `plan.json` SHA256、原 A/B 封包与正式原件、两份同字节的分支输出、冻结原生运行树、原光学权威。使用原 A/B 正控、边界负控、原九张 B 拒绝和错候选联结负控。将脚本、候选及预检散列登记后才打开 EGL。修改范围仅限本轮目录的采集、登记、复核和报告。
2. 按 `plan.json` 九个源 tick 分别执行 q0、+48、+60，同一名义弧长为全槽条件。每个候选从原 B 复位，仅替换七个臂关节的封存向量。使用 `mj_forward`，校核工件、指距、原速度和控制寄存器、相机、时钟及接触。相对原 q0 TCP 位移≤1e-7 m、旋转≤1e-6 rad。原禁碰最小静距严格大于 1 mm，原接触对及数量不变，额外侵入≤1e-9 m。候选 TCP 和指尖独立 FK 回验至原恢复所用 1e-9 m / Frobenius 阈值。
3. 独占原 EGL，使用被冻结的 MuJoCo 3.3.7 原后端与顶视相机，320×240、4× 多重采样、原标定与 GL 型号。每次重置 RNG 为 `default_rng(649300+源 tick)`。先进行九次 q0，逐槽立即比较历史 B 解码 RGB、掩码、有效深度。九槽光学拒绝也须复现。随后各拍九个 +48、+60。总计一次采集机会、最多 27 个原生 RGB-D 请求。任一身份、时钟、散列、重复曝光或 q0 比对错误即停，封存已拍原件和失败，禁止预览、重试、补拍。记录请求、原生事件、同期编码器、相同 RGB 和 depth pass state、无步进与控制、封包 SHA256。
4. 预测进程的可读输入只含当前原生包、编码器、曝光索引/原 OPEN、原标定与轨迹身份所需配置，禁读测试关节分支标签、工件真值和几何结果。预测封存后独立读回，校核候选编码器、原状态、物理净空与已发的姿态误差和间距区间覆盖；两次独立冷读规范 JSON 同字节。按槽报告原 observed/usable ID、合格姿态、两个边沿、支撑和边框、两侧间距区间及严格 0.25 mm 下界、两指严格大于 35 mm 与原 OPEN 条件、逐帧联合许可。缺失结果与所有原拒绝均保留。
5. 原 31 帧连续驻留、真实 RELEASE 返回及每反馈 100 ms 关口仍适用。在线许可、整机、正式仿真、正式独立评分、远程和硬件运行数为零。t02 首次 LIFT 拒绝单列且不触碰。不得把静态关节向量当作动态轨迹。出现新根因需另立 Astra 计划。
