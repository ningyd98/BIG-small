# G1 固定 TCP 封包冷读恢复

Astra 规划模型 `gpt-6.2-astra`。基线 `dd522fad4b6803db8050cd558e115c639aeda558`。两次原冷读均在预检与登记比较处失败，原 traceback 已保留。27 个预检行中的最小碰撞对由运动学返回二元组，JSON 从同样的两个字符串解码为列表。独立复核确认原标定相等，27 行直接比较均失败，完整规范 JSON 同字节。封存捕获的 27 个原生包和原预测均存在。

1. 固定 `plan.json` 的登记、封包和原脚本散列。新入口复用完整原冷读，仅在其私有全局命名空间把静态预检中的二元字符串碰撞对转为保序列表。原选定状态、时钟、标定、阈值、摘要及证据包逐项核查仍由原冷读完成。
2. 用登记副本验证对的换序、单个间距数值改变及漏槽均拒绝。重复执行两个独立进程，输出写入本轮本地独立目录，两份规范 JSON 必须逐字节相同。核对 27 个包、逐帧身份、候选编码器、双 RGB-D pass、原物理联结以及全部封存成员。
3. 新的实质差异、类型门、算法或安全边界失败即保存失败并中止。原脚本、计划、注册、预测、RGB-D 和封包 SHA256 保持。额外曝光、积分、控制、整机、正式、独立正式评分、硬件和远程运行均为零。
