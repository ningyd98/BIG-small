# G1 B03 实际原生放置与连续 RELEASE 驻留

B03 原位 B 和偏移 P 分别用原生 MOVE_TO_REGION、PLACE、测得关节保持及 RELEASE 实际移动和释放。两组在 2840 步前的原生命令、积分摘要和连续物理一致。B 直到 5660 的物理记录与冻结 B 逐项复现。P 将台面目标从 (200,250) mm 改为 (190,220) mm，实际 PLACE 在 5100 步成功返回，RELEASE 在开爪后第 240 步成功返回。原目标区、工件、相机、标定、采样和控制器均沿用原件。[Astra 计划](plan.md) · [逐帧证据](fit03-dwell.public.json)

P 每一帧都以 `id8_opposite_ink` 获得当前姿态，具备台面支撑、原目标边沿和原双侧净空。两侧真实最小净空分别为 4.092 和 5.338 mm，已签发的所有姿态界和间隙区间均覆盖对应真实状态。P 开爪前有独立姿态与支撑可见性，双指仍夹持；该 PRE 帧仅作诊断。B 的 31 帧保留原独立姿态和当前支撑拒绝。P 的最窄下界比三张静态复采的 1.401 mm 小，仍严格大于 0.25 mm。[静态复采](../round-g1-release-fit03-offset-native-20261126/step-report.md)

两路线各采 42 帧，其中 31 张驻留、1 张 PRE、10 张原生隐式图。实际原生运动 11,240 步。两次冷读原先用步末 qpos 与 mj_forward 重算曝光姿态，两次都被 RK4 原曝光缓冲差异拒绝。经 Astra 补充计划，额外 11,240 步无渲染 CPU 原生命令复演逐值复现两路线的物理字段，并逐位核对 64 张显式曝光的编码器、时钟、双 pass 与积分状态哈希。无追加曝光。两份盲预测、两份成功冷读分别逐字节一致。原 RED、原图、先验预测和阈值保留。[原 RED](exposure-reducer-red.txt) · [Astra 补充计划](exposure-replay-plan.md)

P 在该隔离路线取得连续 RELEASE/DWELL 证据。在线 PRE 与全链路反馈时限待实证，原 LIFT 首停仍有效。撤离、整机、正式仿真、独立正式评分、硬件和远程次数均为零。
