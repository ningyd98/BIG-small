# Actual raw-v3 recorder design

## Scope and owner boundaries

Implement only NEW vision/raw_recorder_v3.py, NEW tests/test_visual_raw_recorder_v3.py and the explicitly authorized narrow readonly operation observer context in simulation/mujoco/backend.py. Keep existing raw schema, risk reader/supervision, worker owner, worker/evaluation/execution, event repositories, SkillExecutor/skill robot, camera code, assets and configs unchanged. ROOT later installs this recorder into the sole worker/executor/capture path. This component records actual source operations and never grants owner, native, continuous-motion, INITIAL, METHOD or execution permission. Tests use software fixtures and one explicitly recorded render-disabled passive backend reset/step test; no new episode experiment, model/controller command or renderer.

Frozen design base is raw fix1 774/source manifest67d7524d5f1a7f3981953387c626bcf4d97c64c404f343ebdcd866f6abedc7eb. Seven exact source files are archived in design-source/. Backend/current sources match this base initially. Root has confirmed two pending raw reader compatibility gaps: actual current+clip(target-current,+/-.10)+bias formula, and independent actual camera captured_at versus outside BEGIN UTC. Recorder preserves real targets, control and observation timestamps/checksum; it never rewrites them to obtain COMPLETE. Dependency remains pending until root releases a corrected immutable reader snapshot.

## Approaches and selected instrumentation

Selected: independent backend BEGIN/END observer + recorder wrappers delegating to the exact existing concrete executor and capture. Existing physics/actuator observers remain separate. With no new hook installed the backend follows its original calls/randomness/state semantics. The enabled hook preserves the actual cached camera capture tuple by invoking the same _camera._capture(include_instances=False) already used inside camera.capture, with identical arguments and passes; no segmentation pass is added. Implicit and explicit captures both allocate before calling their operation and retain all failures.

Rejected: reconstructing operation intervals from old post-only callbacks (loses BEGINs and refuses actual duration coverage); monkeypatching live robot/executor methods (risk of recursion/second dispatch path). No observer is used as an authority callback.

## Backend exact interface

`BackendOperationBoundary` frozen dataclass: operation_id:int, kind:RESET|CONTROL|PHYSICS|COMMAND|CAPTURE, phase:BEGIN|END, episode_id:str|None, physics_step:int, sim_time_s:float|None, parameters:immutable Mapping, result:immutable Mapping|None, error_type:str|None, error:str|None.

`MuJoCoPhysicsBackend.observe_operation_boundaries(callback:Callable[[BackendOperationBoundary],None]) -> contextmanager[None]`. One context at a time. BEGIN is emitted before the actual operation, END after actual return or exception. Snapshot/command/camera payloads are detached recursive immutable values. Public mutation/reset/step and observer registration inside callbacks reject using the existing readonly callback guard; no private live array is passed. New hook exceptions are retained in an operation failure ledger and do not stop actual emergency-stop/hold. Observer overhead is measured separately and retained. Backend readonly operation ledger exposes actual allocations/BEGIN/END/error counts so recorder callback failure cannot erase denominators.

Operations: RESET brackets existing reset body; CONTROL brackets existing _apply_control with full actual detached actuator post-control snapshot; PHYSICS brackets each actual mj_step and post-step count/state read; COMMAND brackets each actual public command including refusal/exception, with emergency_stop's internal hold recorded before the stop command interval; CAPTURE brackets actual explicit camera acquisition and each implicit cached acquisition. Existing observer callbacks/rows remain unchanged. No null step, synthetic state, external clock or teleported value is introduced.

## Recorder exact interface

`VisualRawRecorderV3(backend:MuJoCoPhysicsBackend, capture:MuJoCoCaptureSession, executor:SkillExecutor, *, directory:Path, source_root:Path, source_hashes:Mapping[str,str])` is an owning context for new recording files and the new backend observer only. All three concrete instances must share the exact same backend; capture must borrow it; executor must be the existing concrete SkillExecutor with its MuJoCoSkillRobot. Source paths/hashes must be concrete strings and current regular local bytes from a complete recorder policy inventory. Sources are checked at start and again on flush, never admitted from a boolean or cache. Recording directory must be new and lexically nonsymlinked.

`clock_domain_id` is a recorder-generated UUID. Recorder clocks use time.monotonic_ns before and after datetime.now(UTC); UTC uncertainty stays None. Actual boundary samples and measured callback overhead are retained. ClockDescriptor is materialized once source identity is known; all previous actual samples retain original order/timestamps.

`bind_source(identity:RawEpisodeIdentityV3, original_plan:VisualOriginalPlan) -> None`: bind once after actual reset/bootstrap planning, checking actual backend reset episode, recorder clock domain, complete pinned source identities and exact original owner/task/plan/source. This permits retaining reset and initial implicit captures before task/plan identity exists without placeholder/fake identities. Those actual early operations are buffered and journaled; no per-step source or allocation is rewritten when binding later. The binding is SOURCE_CONSISTENCY_ONLY, not actual lease authentication. If reset/planning fails before identity, close persists the full source journal/allocated episode and reports binding unavailable; it does not invent a typed owner/envelope.

`purpose(kind:SETTLE|WAIT|VERIFY_ADVANCE|HOLD|TERMINATION) -> contextmanager[None]`: records the actual caller-owned operation interval; caller executes its existing backend operation inside. No step count is chosen or new controller command sent by this context. All physics/control/commands are joined to their current actual purpose. Exact original SETTLE0->120 is required for evaluation source completion; physics outside a purpose is retained as missing-source diagnostics rather than dropped. TERM has no fabricated step.

`execute_attempt(*, original_plan:VisualOriginalPlan, contract:TaskContract, step:TaskStep, attempt:int, grounding:StepGroundingBinding|None=None, before_acquisition_id:str|None=None) -> StepExecutionResult`: allocate first, preserve exact original compiled requirements and actual executed payload, bracket the sole existing executor.execute_attempt exactly once. Missing actual action_result is an actual REJECTED attempt if the executor rejects before handler/effects; genuine ActionResult (success or failure) is preserved unchanged as RETURNED. Exceptions retain PARTIAL span, known interval/end and actual command/physics counts, then reraises. Root must call this wrapper only after its existing SafetyShield gates; recorder supplies no permission and never calls robot/skill handlers directly.

`capture(*, input_role:SOURCE|ONLINE='ONLINE') -> RGBDObservation`: delegate the exact borrowed capture.capture_with_instances once; actual backend hook allocates and records acquisition, raw camera payload/pass hashes and actual sensor frame. Reconstructing the ordinary RGBDObservation from the same SensorFrame is deterministic and preserves frame_id/UTC/checksum. Frames are persisted with rgb/depth/mask/original observation JSON and optional instance bytes; file hashes are reread at flush. The wrapper returns the same source observation semantics and never renders twice. Implicit cached acquisitions have SOURCE role and are equally preserved.

`join_action_frame(*, span_id:str, acquisition_id:str, relation:BEFORE_SUBMIT|DURING_ACTION|AFTER_RETURN|TERMINAL) -> None`: structural join only to already recorded original identities; validator checks actual temporal/terminal relationship. No new capture, inference, PASS or compensation is implied. Multiple actions/attempts retain original command ranges [c0,c1) and physical ranges (n0,n1].

`flush() -> RawRecorderResultV3`: freeze all current source/journal/allocation counters, original reset/state/controller/delay/timestep, known terminal state and minimum original task/verification/contract deadlines. Build actual RawEpisodeEnvelopeV3/RawEpisodeRecordsV3 and invoke the real raw-v3 consistency validator. Persist envelope.json, records.json, source-journal.jsonl, recording.json and file/source manifest with exclusive names. Callback failures, incomplete operations, missing allocation sources, file/source drift and unknown identity are explicit; cached COMPLETE cannot survive changed bytes. Results are detached immutable data. Repeated flush rereads original bytes and sources; no overwritten legacy raw-v2 or prior episode. `__exit__` closes hooks and flushes even after exceptions, without swallowing original failure.
