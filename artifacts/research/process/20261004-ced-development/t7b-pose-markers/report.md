`detect_pose_marker(observation: RGBDObservation, registration) -> PoseMarkerEstimate` revalidates the complete registered RGB/depth/calibration/checksum before decoding. OpenCV ArUco4x4_50 error correction is disabled. Exactly one expected ID is required. Missing/foreign/duplicate/clipped/insufficient-resolution markers, invalid depth/calibration/checksum, inconsistent nominal size or nonplanar depth return UNKNOWN without pose. Depth comes only from current RGBD 3×3 corner/center patches. Ordered canonical corner axes distinguish 0/90/180/270° rotations. Outputs include observed pixel corners, measured marker center/axes/yaw/edge lengths and frame+registration hashes. Nominal size/2mm planarity thresholds are developmental sanity checks, not calibrated error bounds or continuous stability evidence.
