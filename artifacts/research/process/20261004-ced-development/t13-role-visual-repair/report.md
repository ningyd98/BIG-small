## Behavior and limits

A caller injects an explicitly chosen Max RGBDPlannerAdapter, current RoleRuntimeBinding, REPLANNER CostLedger, typed current source and local grounding callback. Missing binding, selected profile/key, paid permission, source inventory, geometry/motion bounds, canonical conditions or grounder returns unavailable before paid calls. Old role bundles lacking the six mandatory new/current cloud sources fail closed. Direct provider calls reuse the existing builder `_inputs_valid` read-only to check full request identity, current frame bytes, versions, completed effects and graph before transport. Local/B4 window authorization is separate and exact.

The only planner transport seam calls existing private `_request_visual`; public `plan` produces a fixed full pick/place plan unsuitable for preserving repair IDs. Existing request serialization, paired image conversion, raw-body observer and cost ledger are reused. Remote intent must contain the exact binding hash, exactly one original ID per authorized window and unchanged skill. Pixel coordinates use the frozen image size/coordinate convention. Parsing produces no admission, ACK, movement or completion evidence.

The local grounder must return a detached TaskStep with full ActionEvidenceContract, the opaque source binding and an explicit exact candidate-step payload hash. Original pre/postcondition names, complete frozen ConditionSpecs, timing and retry limits must remain unchanged. The proof must bind current plan/sequence/checkpoint/frame and full maximum(timeout, expected duration) horizon. Duplicate conditions, stale proof, decoy targets, unknown geometry and nested execution/safety overrides reject. Caller context and callback input mutations are isolated and rejected. Revalidation occurs after the model call and after grounding.

B4 changes only the authorized pending window; it keeps the same failure/request/frame/source and preserves completed effects and disconnected pending steps through the existing builder. The software LocalReplanningService integration test stores a PREPARED candidate with no stage/resume ACK, activation token or start receipt; old active plan remains current.

### Safer remote payload ruling

Automatic approval review rejected a proposed full-state wire expansion before execution because internal contracts/checkpoints/robot state/facts/dependencies/action evidence were not specifically authorized for the remote destination. There were **zero real calls and no rejected production edit**. Root selected a safer alternative. The final wire contains only task instruction, the existing two RGB-D-derived images, opaque request/frame/window/context/source/bundle/schema bindings, original authorized step ID + skill, and fixed `STEP_REPAIR_REQUIRED` enum. Full request state, parameters, world/camera poses, checkpoint, robot state, visual facts, dependencies and complete ConditionSpecs remain LOCAL. The model receives intent context, not full local proof contents; local validation and grounding must supply what it cannot establish. The expansion was not retried. Evidence: `rejected-expansion-no-call.log`, `red-full-wire-context.log`, `intent-trim-baseline/`, `red-intent-only-payload.log` and the final allowlist test.

## Public interfaces

- `RoleVisualRepairSource(context: VisualRepairContext, action_evidence: Mapping[str, ActionEvidenceContract], evidence_scope='UNAVAILABLE')`: detached full local source; computed `source_hash`. Scopes: UNAVAILABLE, SOFTWARE_ONLY, ACTUAL_SOURCE. Scope is provenance metadata, never physical admission.
- `RepairReplacementIntent(step_id, skill, target_pixel, destination_pixel)` and `VisualRepairIntent(schema_version='role.visual-repair-intent.v1', binding_hash, replacements)`: extra fields forbidden; strict JSON validation.
- `GroundedRepairStep(step: TaskStep, action_evidence: ActionEvidenceContract, source_binding_hash: str, payload_hash: str)`: full local proof plus explicit candidate payload hash; constructor verifies the hash.
- `GroundingProvider(intent, original_step, observation, visual_context, binding_hash) -> GroundedRepairStep`.
- `RoleVisualRepairProvider(*, planner, binding, source, grounding_provider, clock=None, full_remaining=False)`: callable matching existing RepairProvider; exposes `validate(...)` and last opaque `last_binding_hash`.
- `SourceProvider(request: LocalReplanningRequest, service_context: ReplanningContext | None) -> RoleVisualRepairSource | None`.
- `RoleVisualReplannerAdapter(*, planner, binding, source_provider=None, grounding_provider=None, full_remaining=False, clock=None).replan(request, context=None) -> LocalReplanningResponse`: existing adapter protocol. Unavailable paths return no steps and constant local reasons; software candidate planner name explicitly ends in `software`.

`REQUIRED_SOURCES` requires cloud snapshot source hashes for provider, adapter, visual_repair builder, visual_dependencies, planner and messages. Existing RoleRuntimeBinding additionally checks edge/device source inventories and actual effective request settings. A future actual probe must extend its source-fingerprint inventory and freeze these paths; no probe/config code was edited here. API unknown weight digest/revision/quantization remain null through existing snapshots.
