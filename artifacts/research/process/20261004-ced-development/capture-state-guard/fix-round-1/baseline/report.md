The independent MuJoCo state-snapshot module is ready for bounded software review. It changes no collector, backend, controller, camera, old guard or frozen attempt, and grants no acceptance authority.

The module derives all 60 solver/dual/island getters from exact frozen MuJoCo 3.3.7 header bytes. The contract also checks the frozen binding pin and explicit runtime version. Each public ndarray is fetched once and immediately copied. Genuine nonowning views retain full byte SHA256 plus shape, dtype, dtype descriptor, support and inventory. A positive-size owning/base-none array can become `UNSUPPORTED_NULL_ALLOCATION` only when its exact dynamic declaration, shape and dtype match this contract; its bytes remain unavailable as live-data evidence. Known empty arrays retain `EMPTY` structure. Unknown owning arrays, including unknown empty arrays, fail closed.

Support transitions, shape, dtype and inventory enter the same digest domain as all genuine field bytes. Active dynamic fields therefore re-enter full byte protection automatically. There is no five- or seven-field exclusion. The composition interface requires all 11 original protected model/options/controller/RNG/cache/camera/step/command/noise/time/physics components, includes any extra finite JSON state, and detaches nested mutable payloads.

Three qualified legacy RED cases cover island/dual placeholder read variation and unknown owning storage. Two further RED cases cover inconsistent immutable record metadata. Final validation: 44 tests passed in 0.37 s; Ruff passed; single-production-file mypy passed with only the existing unused-override note. Two tests restore four original gzip snapshots' byte vectors and ownership categories without constructing or calling MuJoCo. All source/contract/snapshot inputs are pinned in `source-hashes.json`, `source-archive-index.json` and `header-contract.json`.

This work made zero model, renderer, physics, provider, decoder or Git calls.
