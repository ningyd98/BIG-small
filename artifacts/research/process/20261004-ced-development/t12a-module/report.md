## Behavior and exact interfaces

- `build_candidates(context, *, action_contracts=None) -> CandidateSet` retains all five actions and each unavailable reason. STOP is always present. LOCAL_RECOVER remains explicitly disabled pending T13's actual module/source/calibration admission. Physical CONTINUE requires finite calibrated action risk and geometry/motion bounds, current full contract, canonical exact-target preconditions, capabilities and non-atomic boundary. Final verification failure cannot reuse previous condition PASS. REOBSERVE requires a task-level allowance; REQUEST_CLOUD requires current observation/calibration/identity/sensors and actual positive TTL, plus failed-verification retry allowance.
- Candidate IDs bind task/episode/frame/current plan/command/mode/context. `CandidateSet.content_hash` binds immutable action availability, reasons, complete contracts and exact condition parameters; duplicates, missing STOP and mismatched hashes reject. Provider return rechecks this hash, legal membership and fresh evidence.
- `ActionCostEstimate`, `estimate_action_costs(context, CostSnapshot, weights)` and `score_actions` use T9 action-conditional probabilities and T8 measured aggregates. The future REQUEST_CLOUD heuristic uses mean aggregate inference/network/switch components per sent model attempt because the ledger has no per-action timing attribution. Missing inference stays None; provider RTT is never substituted. Unknown costs/probabilities remain unranked. CONTINUE/REOBSERVE/STOP make no model/transport/mode request themselves, so those structural request costs are zero. Active STOP pays configured task-failure loss without inventing probability 1. Hard STOP bypasses cost competition.
- `CostDecisionJudge.choose(context, candidates, estimates)` ranks legal known costs and breaks ties by candidate ID. Its `rule_scores` are costs, `candidate_probabilities` and `reported_confidence` are None. Provider identity binds actual judgment source; the default policy instance also binds frozen policy/weights/risk/source identity. Injected provider mappings are immutable copied; malformed/ABSTAIN/out-of-set/timeout/conflicting output becomes budgeted new capture or STOP, with original returned judgment separated from fallback disposition/reasons. Rules send no HTTP/model requests and never increment the shared ledger.
- `JointEvidencePolicy(risk_model, weights, cost_ledger, judge=None, *, contract_provider=None, software_only=False, clock=None, admission_provider=None, trace_sink=None, judge_timeout_s=1)` reads `cost_ledger.snapshot()` inside `decide`. Root-approved `ContractProvider(context) -> Mapping[DecisionAction, ActionEvidenceContract]` avoids modifying shared DecisionContext. Current online contracts are copied immutable. Missing contracts/expired evidence route a new capture. Same frozen event returns the reserved action without a second allowance, including the last allowance; changed duplicate evidence/risk/cost input STOPs. Hard-stop and default admission gates precede ordinary contract/judge providers.
- `DecisionTrace` freezes candidates, full version envelope, estimates, provider judgment, disposition, failure reasons, event IDs, actual cost snapshot, declared risk artifact hash, frozen weights/source hashes, observation checksum/calibration and separate measured rule/provider elapsed time. `policy.traces` is an immutable in-process audit tuple. Supplying `JsonDecisionTraceSink(directory)` provides fsync + atomic no-overwrite hashed `ced.decision-trace.v1` JSON artifacts. Identical saves are idempotent, conflicting IDs reject. Sink failure propagates before any action is returned and never silently reserves another allowance.

## Actual research admission and physical boundary

Default `software_only=False` always returns **NOT_ADMITTED STOP** with `adaptive_not_accepted` and `actual_admission_verifier_unavailable`. A bare flag/hash or caller-created admission object cannot enable actual adaptive choice. `JointPolicyAdmission` and the default-None `AdmissionProvider` describe a future source-verification request only; the hook is not an acceptance mechanism in T12a. Root explicitly approved this default fail-closed boundary. Actual source-bound weight admission remains dependent on verified current INITIAL, source-accepted T9 model/calibration, immutable current sources/contracts and preregistered finite weight candidates with actual complete selection outcomes. Exploration needs INITIAL/calibration and preregistered candidates first; it cannot circularly require its own selection result before evaluation.

Explicit `software_only=True` permits only fixture math. Every SOFTWARE_ONLY selected trace has `valid_until == created_at`; trace construction rejects a software record that grants future ordinary physical authority. Atomic ordinary decisions return CONTINUE solely as **DEFERRED_ATOMIC**, with no new physical permission. Hard STOP is immediate independent of ordinary providers, dwell and selection. Root must continue to use the existing executor/SafetyShield/T10 commit recheck; this policy has no dispatch entry point. No actual physical trace was emitted.

The envelope expiry helper derives validity from min(real observation TTL, absolute verification deadline, bounded-error/motion action completion horizon). Unknown bounds, missing/naive/reversed clocks and missing TTL cannot create physical validity. REOBSERVE may request a new capture despite stale previous input and records `requires_new_capture`; REQUEST_CLOUD needs fresh actual TTL first. STOP validity equals creation time for audit only. Software traces remain expired even when the helper's bounded horizon is positive.
