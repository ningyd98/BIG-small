# Initial visual bootstrap and worker connection

The real worker creates its first immutable plan after capture and cloud planning. An ordinary owner route cannot exist beforehand. Add a separately named BOOTSTRAP_SOURCE_ONLY record in the same existing event repository, never a fake original, partial verification pool, extra executor or accepted flag. The root owns new `event_autonomy/visual_bootstrap.py` plus its dedicated test. After the current ordinary-route increment is frozen, extend protocol/memory/sqlite under exclusive handoff; the route producer's frozen version stays intact. Root will then connect the actual worker/evaluation/execution boundary, preserving the explicit LEGACY default and absent-source refusal.

Bootstrap definition binds the actual job/run/current attempt/lease snapshot, episode, instruction, role/model/source hashes, task start and original verification limits. One key per job/run is retained across retry/restart; a new episode/lease/attempt is a conflict until an explicitly reviewed handoff exists, never a new budget. Absolute task and verification deadlines are computed once from the task-start source; constructing a definition is not authenticated source, native or METHOD permission.

A strict immutable bootstrap record tracks exactly one pending capture/request claim, completed registered frame, planning receipt, remaining reobservations/retries, original deadlines, no-progress, rounds, clock high-water and bounded history. Repository transaction time drives transitions. Reserve initial capture once; reserve a planning request once per registered frame; only a completed unusable planning source can reserve a new reobservation, consuming it before capture. Missing, changed, duplicate, late, exhausted, cancelled, hard-stop or foreign sources cannot issue another effect. Claims are source-history facts, not effect authority: worker must check its actual lease/backend/roles/hardstop before and after every effect. A crash/lost reply leaves a pending claim spent; only STOP/reconcile is permitted, never refund or replay. Historical duplicates are separately marked and never trigger an effect.

Completion accepts concrete registered RGBDObservation or concrete PlannerDraft, detached through strict codecs with undeclared fields/nonfinite/coerced counters rejected. It binds the exact active claim, actual source timestamps and content hash. Bootstrap validates provenance/consistency only: parsed planner JSON never establishes native preconditions or an execution route. A planning result is usable for source promotion only when the exact schema-owned proposal is present with no parse_error/sentinel, observation evidence matches the claimed frame/episode/model/role and full camera descriptor, and its original full contents are preserved. Malformed/ambiguous/unsupported semantics fail closed during canonical original compilation. The original assistant raw text is retained separately from the locally produced semantic proposal, because the current adapter constructs the latter from VisualDecision.

Atomic promotion belongs to the existing owner initializer transaction with an explicit expected bootstrap hash. Require exact current completed planning receipt; original identity/role/source/proposal/observation/deadline coverage and strict full remaining verification state match. Original plan, active contract, checkpoint, normal verification/retry pools, owner publication and bootstrap ADOPTED record commit together or none do. Retry producer remains the sole consumer of retry authority. Existing old owner initializer without a bootstrap remains compatible; if a bootstrap exists it cannot bypass promotion checks. Never claim atomicity with the separate runtime-job/mode databases.

Required RED/verification: source aliases and strict schemas; absolute deadlines and clock rollback; repeated reserve/complete/event/new UUID/frame; pending lost capture/request; all original reobservation/no-progress limits; usable versus sentinel/error planning receipt; frame/model/role/calibration drift; original semantic/proposal preservation; exact promotion with already spent state; SQLite two-connection race and failure rollback; restart/new attempt cannot refill; pre- and post-effect lease/hardstop checks; no callback verdict, fake original or native permission. Software tests use new synthetic frames and explicit software lease snapshots only; they must not retimestamp saved physical sources or claim actual capture/call.

Whole integrated acceptance still requires fresh worker/runtime sources, calibration/native geometry/motion, actual after-effect/hold and terminal provenance, METHOD/INITIAL/FINAL gates and independent billing. No bootstrap source or software test bypasses those gates. Edge model stays deferred.
