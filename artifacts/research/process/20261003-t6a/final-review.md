## Findings resolved before acceptance

1. **P1 — Dataset finalization can exceed the configured disk cap and return COMPLETE.** Initial `generator.py:351–370` writes split copies of every record, the audit, quality report and manifests without reserving their bytes. Per-record payload reserve does not cover total finalization growth. CPU-only reproduction using `test_rgbd_dataset_generation.cpu_factory.__wrapped__`, `groups=20`: baseline bytes immediately before `write_splits` were 1,211,655; a new run capped at 1,361,655 returned COMPLETE with 20 groups and 1,631,604 bytes (269,949 over cap). Measured output: `final-review-budget-repro.json`. Root delegated correction and regression to `t6_quality`.

   During correction review, the same budget issue was reproduced for rejected-attempt journal growth: with the CPU fixture, `groups=1000`, `max_bytes=190000`, and every proposed scene fixed to seed 0, generation stopped after 767 attempts/one group at 190,091 bytes. It returned INCOMPLETE but could not persist its terminal manifest. Evidence: `final-review-journal-budget-repro.json`. The owner was notified to reserve attempt/outcome/status overhead too.

2. **P2 — Resume source binding omitted runtime Pose contracts.** Initial `generator.py:57–63` includes dataset/capture/simulator code but not `contracts/models.py` or `contracts/__init__.py`. `RGBDObservation.world_point` instantiates `Pose`, and physical scenario construction consumes the same contract. Changes there would leave the recorded source hash unchanged and permit a resumed dataset with different contract code. Root was notified before formal generation/freeze.

Both findings are now resolved in the frozen source. Finalization reserves the serialized split/audit bytes and bounded report/terminal-manifest room, then checks actual report/manifest sizes again before publication. Atomic temporary copies are checked against free space; `max_bytes` explicitly covers retained dataset files. Journal writes reserve their actual append bytes plus outcome/terminal-manifest room before consuming an attempt. Insufficient initial metadata space returns INCOMPLETE without publishing metadata and reports `manifest_persisted=false`. Final retained-byte measurement includes the final manifest itself. Runtime contracts and relevant package/adapter dependencies are now included in the source fingerprint.

The independent generator rerun includes the original 20-group cap reproduction and the 1000-requested-group repeated-scene journal reproduction as executable regression tests; both pass. Ten dependency-fingerprint tests confirm that modifying each newly covered dependency changes the source digest without modifying real files.
