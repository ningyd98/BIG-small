# 连续视觉抓放修复

用户在阅读 `artifacts/research/process/20261117-grasp-place-analysis/report.md` 后要求“修复”。沿该分析建议，由当前模型直接实施、验证，复用现有隔离 worktree。范围是注册 MuJoCo 抓放链及已确认的途中持物丢失缺口；真实模型、真机、公开推送和手指轨迹不在本轮操作中。

## 方案与约束

采用绑定 task/step、起点和冻结终点的显式竖直脱离路径，供安全检查与实际运动共用。拒绝只扩大通用 x/y 比较容差，也拒绝每帧重置横向起点。没有路径的调用继续执行原严格规则。

路径仅用于 LIFT/RETREAT，目标在起点正上方且达到至少 80 mm 安全高度。工程选择：横向偏离上限 1 mm、相对已达到高度回落上限 1 mm；均小于现有运动收敛位置容差 5 mm，属于开发运行约束，不是物理标定证书。控制器在每个物理步检查，越界 hold；如现有关节插值无法保持约束，则改为受约束的笛卡尔中间目标，不扩大约束来通过测试。路径目标被视觉回调改变时拒绝。

安全上下文显式绑定预期持物 ID 与当前反馈 ID，持物任务发生不匹配时拒绝。运动适配器还需在每个物理步检查接触丢失，不等运动完成。已有“有双侧接触”只表示候选持物；完整成功仍由独立物理评分判断物体抬升 ≥50 mm、保持 ≥0.5 s，以及释放后放置稳定 ≥1 s。

不降低安全高度、不扩大工作空间/关节/速度界限，不读取物体真值来控制，不重置任务/步骤预算，不放宽完整视觉几何或复用旧帧。新增安全/控制源码纳入角色绑定。后续真实运行若暴露后续根因，先记录实际失败，再用最小修改和失败测试修复；保持原始失败字节。

实际诊断补充：单靠精确 IK 的短目标无法消除位置执行器的接触载荷和动态滞后，数次孤立试验均触发 1 mm 停止。独立对照在同一模型、同一手指轨迹和边界下，用四秒五次平滑竖直参考、机器人模型惯性/阻尼前馈及关节反馈外扰估计通过了孤立路径检查。实施时将其作为路径专用控制，通过公开、可审计的原 `joint_target` 接口发送，并继续限速/限加速度；不修改 backend 执行器输出、不读取物体自由关节。初始工具姿态已在标称 5° 范围时，脱离段冻结实测姿态。成功须在参考结束后稳定 0.5 s、速度/加速度指令归零并保留平衡载荷的末端保持目标；失败依旧立即取消待执行轨迹并 hold。孤立成功不代表完整 worker 或泛化通过。

入口采用原载荷稳定判据的关节速度 ≤0.02 rad/s，否则在第一条运动指令前拒绝，不重绑起点掩盖惯性。完整 worker 通过抬升后，在 MOVE_TO_REGION 第296步实测手腕遮挡目标区一角；原完整像素矩形准入拒绝该帧。动态模式允许用初始完整世界矩形按本帧外参重投影核验静止目标区，要求至少三个当前角点锚、所有当前颜色支持均落在原世界几何/平面内，且每一个缺色内部像素均有当前有效、明确高于平面的前景深度。无深度、共面涂改、额外同色干扰、少于三个角点、裁切或标定不符一律拒绝。旧固定相机 tracker 的规则不改，未补造隐藏物体尺寸或赋予正式几何资格。

用户补充“摄像头不一定一直在顶端”。据此将本轮开发相机扩展为可移到侧上方并朝向实测工作区；相机原位置范围与冻结执行限制保持。每帧 RGB/深度仍在同一物理状态、同一标定下配对，完整旋转和平移外参参与反投影，位姿变化必须对应新标定版本。工程选择：由当前注册标记、初始实测物体范围和完整目标区提出斜视位置，全部已知特征须落在图像内，随后每一帧仍需真实识别和深度核验。相机位置可观测，不把相机运动解释为物体运动，也不凭预期投影补造标记。

此前为固定顶视遮挡而增加的 x/y 两段运输撤回，恢复到原登记终点的直接运输；仅低位释放后的 RETREAT 保留竖直脱离再横移，两段共享原步骤的 10 秒时钟。顶视方案实际还复现运输途中工具倾斜约 12.45°，同时独立物理观测显示物体倾斜，根因是终点 IK 后的各关节独立插值。后续对照验证将笛卡尔姿态保持和原机器人动力学前馈扩展到运输/放置；不提高 upright 门槛、不改 backend 原 target-error 夹限，也不把规划前馈余量当成实际不会触发夹限的证据。

目标区深度判据保留标定误差界；没有标定界时仅采用原开发可见平面的 8 mm 带作身份核验，并继续标记正式几何资格 UNKNOWN。颜色轮廓外沿若 RGB 仍为绿色而配对深度已是明确前景，将其作为遮挡而非目标平面；内部飞点、无效或无法解释的缺色仍拒绝。已有逐像素证据只证明颜色/深度边缘混合，不证明其渲染归因一定是 MSAA。

真实多视角对照发现，PLACE 时红色方块的贴地侧壁高出目标区约 3–4 mm，却低于平面可见性带；这些像素全部紧邻已测高前景，不能归为目标区外边界误差。对这种侧壁只允许当前高前景的一像素邻域，要求配对深度在传播当前像素足迹和已有标定误差后仍高于实测平面，且 RGB 是初始目标颜色或目标/区域两种已知颜色的边缘混合。独立低矮色块、共面缺色、无效深度、异色和内部飞点仍拒绝；未标定输入仍不授予误差界或完整几何资格。

主动视觉限定在本轮仿真：每次采样可因遮挡或标记不可见尝试最多两个其他预先计算的、原相机范围内的视角；全部捕获与归档计入原 0.1 s 采样 deadline，机器人仿真在换视角期间不推进。每张候选都重新检查真实标记和区域锚点，不复用失败帧作为成功证据。标定、无效深度、身份、物体不直立及目标跳变错误不触发重试。首轮完整 worker 因换视角耗时 0.124767 s 正确停止；随后仅消除旋转相机下必然无用的固定矩形分析，以及没有低位侧壁时的重复像素工作，不扩大时限。

后续逐像素实测细化：侧壁的正高度像素可连续连接到高前景；混合边界允许落在该已测前景的一像素足迹内。仅未标定开发可见性可排除“RGB 为两种已知颜色混合、深度落在平面可见带”的边缘像素，且不将其计为平面支持；标定输入仍要求正高度。当前绿色支持在相邻一像素范围内沿用 tracker 已有的去灰色度判据处理光照，深度尖峰和无效深度仍拒绝。历史原件保持；高频新帧使用无损 PNG 0 及直接读取原始 float32 深度，减少两视角采样耗时，校验和、每帧标定与同物理状态配对检查均不减少。

独立物理成功与流程完成分开验收：首次抬升、落位成功的 worker-active-camera-10 在释放后仍因无关的目标区唯一颜色门槛停止，不能称为完整流程通过。RETREAT 仅用机器人反馈绑定脱离/撤离终点，不消费目标区几何；其当前注册标记及安全检查继续生效，MOVE_TO_REGION/PLACE 仍必须有当前目标区支持。加强集成用例，要求物理成功、诊断完成、无终止错误、撤离及终帧标记可见同时成立。

## 验证

先复现原抓放失败以及无持物动态检查仍通过，再验证路径身份/终点绑定、低位横移拒绝、每步偏离/回落/掉物停止和异常 hold。完整 worker 使用现有外部模型协议替身，实际 MuJoCo/RGBD/SQLite/SafetyShield 不替换，以独立 `physical_success` 及全过程证据验收。串行图形测试避免相互干扰，记录实际墙钟吞吐。

实现后执行相关回归及全仓库 pytest，保留并列出既有失败，运行静态检查和一次独立代码审查。本轮源代码提交前必须完成真实仿真验证；软件测试通过不授予正式研究或 native action 资格。

最终运行补充：整库续测真实暴露 LIFT 尚无备用视角，新增包含冻结抬升高度的实测候选，仅遇可恢复的当前观测损失时换视角。两次后续 PLACE 在同一侧视→总览切换点超过 100 ms，因此在 PLACE 开始前重新获取原实测总览；不扩大采样期限、任务/步骤预算或视角范围，新帧仍独立核验。此前失败保留；最终三次完整 worker 与 220 项相关回归通过，整库分段快照和最终源码的验证范围分别记录。
