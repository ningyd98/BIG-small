# 连续 OpenCV 视觉伺服与可调顶视相机

用户授权实现连续高速视觉伺服，并允许通过改变相机位置调节视野。当前系统仅在技能前更新坐标；本次将反馈接入技能内部的运动循环。保留云端 Sol、Molmo 选点、注册标记、顶视方向、现有机械臂与硬停止边界。实现和验证首先针对 MuJoCo；不生成真机许可或正式研究验收。

## 方案与范围

采用 RGBD 世界坐标位置伺服（PBVS）：OpenCV 在运动中重新测量，既有关节轨迹限制器执行最新目标。纯图像误差伺服需要额外的图像交互矩阵与深度控制标定；仅增加技能前采样不能满足连续反馈。本次选 PBVS，是实现者基于既有链路的选择。

默认视觉周期 1/30 s，关节控制沿用约 0.02 s，物理周期 1/240 s。采样期限取物理网格上界，记录实际仿真采样间隔及墙钟耗时；不把仿真 Hz 冒充真实实时性能。视觉循环不调用云或本地大模型。

支持顶视相机在世界坐标中平移（包括高度），逐帧使用本帧外参。相机旋转、变焦、自动寻找最佳视点及真实相机驱动不在本次范围。相机变化必须伴随更新的标定版本；保留旧固定相机跟踪器的严格绑定。RGB 与 depth 捕获期间相机/物理状态必须不变。

## 接口与行为

- 新视觉反馈提供器从初始完整、唯一颜色目标/区域建立身份；每帧使用原始 RGBD 和当帧外参测量。指定注册标记时，先要求其抓取点与初始选中目标相距不超过 0.01 m，再将该标记作为连续测量来源，避免中途切换坐标来源；标记丢失停止。未绑定标记时逐帧要求完整颜色几何。二者都不构成物体表面完整性证明。
- 反馈提供器对 MOVE_ABOVE / APPROACH 更新抓取目标；对 MOVE_TO_REGION / PLACE 更新当前完整可见放置区域位置；LIFT / RETREAT 冻结技能起始终点并持续检查观测，保留既有注册的退让偏移。GRASP / RELEASE 保留原手指指令轨迹。
- 进入伺服会话显式绑定采样函数及参数；每次运动调用独立会话，退出后清除。无会话时既有控制器行为不变。
- 视觉反馈每帧重新核验 episode、scene、来源、分辨率、内参、外参、时间及帧唯一性。默认最大观测年龄/仿真间隔 0.1 s、单次位置变化 0.01 m、相对技能初始目标最大校正 0.05 m；这些是实现选择，不能提高既有安全上限。
- 控制器继续使用真实关节执行器和 mj_step；保留速度/加速度限制、关节范围、急停、取消、租约、物理预算和 SafetyShield。动态目标必须再次经过调用方安全检查。连续三个新鲜视觉样本与 TCP 误差达标才报告运动收敛。
- 控制/视觉期限分别为 5/8 个物理步，必要时仅拆分物理步进；不能用变长命令周期破坏速度/加速度上限。显式伺服作用域按视觉期限采集，避免每个控制 chunk 重复渲染，作用域退出恢复默认采集。
- 任何采样/检查异常必须先 hold 当前关节并传播失败；过期、重复、越界、歧义、丢失或不可达目标不得沿用旧目标继续走。硬停止和独立物理评分不由视觉结果替代。
- LIFT 运动后的 0.5 秒接触保持保留原轨迹，继续采集视觉并核验冻结终点；POST 使用当前最后一帧与同一动态目标，不能复用运动开始前或保持前的旧帧。
- 组件诊断通过明确角色策略与 job 参数选择新模式，并将相机位置和伺服配置纳入角色绑定、源码指纹与审计。旧冻结物与既有结果保留原样。
